# 第 14 章复习卡：Python 测试框架与用例组织

学完讲义和实验后使用；说不清原因时回到对应例子。

## 1. 一条测试的执行过程

```text
确认解释器与命令
→ 读取配置、加载扩展
→ 导入与收集、筛选测试项
→ 按 fixture 依赖准备
→ 执行测试体和业务断言
→ 清理已进入的资源
→ 解释节点、阶段、退出码与报告
```

配置或导入可能在测试体之前失败；测试体 passed 后还可能 teardown error。

## 2. 核心概念对比

| 对比 | 区别 |
|---|---|
| `-k` / `-m` | 名称等关键词筛选 / 按标记表达式筛选 |
| collect-only / 运行测试体 | 前者仍可能执行导入和收集代码 |
| 参数化 / 测试内循环 | 每组独立测试项 / 通常失败后停止当前循环 |
| fixture 请求 / 手动调用函数 | 框架解析依赖和缓存 / 普通调用 |
| fixture scope / 数据不可变 | 共享寿命 / 对象能否被修改，两者独立 |
| 工厂 fixture / 一份资源 fixture | 返回创建入口 / 返回一份供使用的结果 |
| skip / xfail | 按条件不执行 / 通常执行并期望失败 |
| mock 交互 / 业务断言 | 调用谁、多少次、哪些实参 / 返回和状态是否正确 |
| 阶段计数 / 独立节点数 | 同一项可能贡献 passed 与清理 error |

## 3. fixture 与对象共享

- 默认 function；更大作用域适合确实可以共享的条件，不自动隔离可变对象。
- 单项内多个依赖请求通常复用缓存；不等于每个形参各创建一份。
- 准备顺序看作用域、依赖和 autouse，不能依赖名字或函数定义顺序。
- 存在依赖时先准备被依赖者，成功进入的部分逆序清理。
- yield 前失败，不能等靠后普通清理语句；取得后及时登记或使用 ExitStack。
- 较大作用域直接请求较小作用域可能 ScopeMismatch。
- conftest 按目录可见，子目录可局部覆盖；不手动导入 fixture。
- indirect 将参数交给 fixture 的 request.param；简单输入不必绕一层。
- 高成本基础可以共享，可变用例状态按明确边界单独建立。

## 4. 断言、替身与恢复

- expected 来自需求，不从 actual 复制。
- raises 范围只包含目标动作；异常类型和拒绝后的状态分别检查。
- `match` 使用正则；精确异常类型可检查 `type(info.value)`。
- patch 实际查找位置：`from provider import read` 后通常替换使用模块的 read。
- monkeypatch 恢复登记的修改，不撤销任意内部状态或远端副作用。
- autospec 约束签名，不保证真实集成或业务返回内容。
- side_effect 控制逐次结果或错误；失败调用也计入 call_count。
- AsyncMock 的调用与等待分开检查；普通 pytest 不原生执行 async 测试体。
- 时间、随机、环境、文件分别控制；固定种子不固定调度和真实时间。

## 5. 结果与诊断

| 结果或工具 | 复习重点 |
|---|---|
| deselected | 本轮未选中，不是通过 |
| skipped | 原因和条件可见，不能计作业务已验证 |
| XFAIL | 对应已知问题，限制类型并维护原因 |
| strict XPASS | 提醒可能已修复，通常使会话失败 |
| capsys | readouterr 分段读取，不返回累计全部历史 |
| caplog | 检查记录、级别、消息和关联字段 |
| JUnit XML | 结构化结果，不默认带所有附件和日志 |
| 临时目录 | 每项路径独立，不保证测试后立刻删除 |

退出码常见 0 成功、1 测试失败、2 中断、3 内部错误、4 使用错误、5 无测试。收集错误可能导致 2；结合阶段和具体报错判断。

## 6. 配置、并行与扩展

应用配置覆盖规则应显式规定；缺失不等于所有假值。无效全局选项尽早 UsageError，避免只在某个 fixture 内校验而被绕过。

session 通常属于每个 worker 会话，不能当跨进程唯一资源。独立 Python 内存不隔离固定文件、端口和远端记录；并行扩展不是本章默认依赖。

单独通过、整组失败时先查共享对象、模块全局、环境、路径、缓存和顺序依赖。重试需保留首次失败、次数和最终结果，不把最后一次通过当成全部证据。

重复转换用帮助函数，生命周期用 fixture，重复业务检查用断言组件；组合与基类按责任选择。小范围 hook 放 conftest，多工程确需复用才提取插件，并测试默认、覆盖、非法值及兼容行为。
