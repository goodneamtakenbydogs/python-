# 第 16 章复习卡：Python 测试工具开发

学完讲义与实验后使用，不代替首次教学。

## 1. 工具开发的完整过程

```text
明确用户、最小需求和完成条件
→ 写输入、输出、异常与资源约定
→ 模型、配置、读取、核心和报告分工
→ 单元、集成、CLI 与失败路径测试
→ 测量明确范围，优化热点
→ 构建 sdist/wheel
→ 在干净环境安装并验证真实入口
→ 自动检查、记录版本与维护兼容性
```

工具要解决具体任务，抽象和依赖按实际需要增加。

## 2. 主要概念对比

| 对比 | 区别 |
|---|---|
| 核心接口 / CLI | 接收明确对象 / 适配终端文本、环境与退出 |
| 类型标注 / 运行时校验 | 描述意图 / 显式拒绝不合法输入 |
| frozen / 深度不可变 | 限制外层重新赋值 / 内部可变对象仍能改变 |
| 输入总数 / 选中总数 | 整体验证范围 / 当前统计范围 |
| 流式 / 常数内存 | 分步读取 / 还需分析保留集合与输出 |
| workers / max_in_flight | 运行上限 / 已提交未交付结果上限 |
| 取消请求 / 实际停止 | 控制策略 / 正在运行工作仍需收尾 |
| 发行包 / 导入包 / 命令 | 安装名 / import 名 / 终端入口名 |
| 可编辑安装 / wheel 验证 | 开发源码关联 / 实际分发物可用 |
| schema_version / 发行版本 | 数据格式约定 / 软件发布版本 |

## 3. 数据与模块规则

- 公共接口说明输入、返回、异常和副作用，不要求调用者先理解 CLI 对象。
- 入口依赖核心，核心不反向读取 sys.argv 或全局环境。
- 配置覆盖和校验时机显式规定，未知字段与文件 null 不静默忽略。
- 空筛选明确选择零项，不用 or 自动变回全部。
- 按协议校验和规范化，再检查唯一性；过滤不能隐藏未选数据的错误。
- JSON 能解析不代表字段和业务含义合法。
- 物理行号包括空行，字符数与 UTF-8 字节数不同。
- 一次性输入不保证 len、重放或二次消费。
- 错误类型用于分支，字段用于定位，原因链保留底层证据。

## 4. 资源、结果与取消

单行字节上限、总记录上限、运行并发、在途 Future 和输出积压分别分析。编号集合与耗时列表有实际空间成本，不能只凭 generator 就说 O(1) 内存。

报告准备与提交分开，先全部验证，序列化后同目录写临时文件，关闭后替换。输入或提交失败不发布半份新报告；旧报告的 run_id 不属于本次成功证据。

只清理自己取得的资源和临时文件，清理错误保留证据；不以 glob 删除其他文件。替换可见性不等于断电持久性、多文件事务和并发仲裁。

部分消费的生成器要明确 close。批量完成按 index 关联，单项错误保留类别；budget 不强制杀线程，shutdown 可能仍等运行项结束。

## 5. 自身测试的层次

| 检查 | 主要证据 |
|---|---|
| 模型、解析和汇总单测 | 类型、边界、空输入、重复、筛选与计数 |
| 临时文件与故障注入 | 编码、行号、状态传播、旧目标与清理 |
| main 与真实模块调用 | 参数、环境、退出、通道和组件协作 |
| wheel 干净安装 | 分发文件、元数据、导入位置与实际命令 |
| CI job | 指定提交在声明组合中的自动验证 |

正确实现通过，典型错误应被发现；测试总失败也不是有效区分。expected 不能只从 actual 复制，覆盖率不能证明需求和断言完整。

## 6. 构建与维护

pyproject 声明元数据、依赖范围、后端和入口，锁文件固定解析结果，.venv 是本地安装现场。运行、开发和构建依赖分开，不把开发环境目录作为交付物。

src 布局降低仓库路径造成的假成功，仍需干净安装。新环境只装 wheel，从源码目录之外运行，移除 PYTHONPATH 干扰，并核对 __file__、发行版本与命令。

Ruff、pytest、构建、安装验证互补。CI 配置存在不代表实际运行成功；看对应提交、job、失败步骤和产物。版本标签也不代替兼容测试。

## 7. 性能证据

说明输入规模、环境、重复次数和包含的开销。timeit/perf_counter 测所选路径，cProfile 看调用热点，tracemalloc 看部分 Python 分配；都不能直接等同系统压力、端到端性能或进程全部内存。

优化后重验行为、错误和资源约定。一次测量较快，不代表所有输入更快。

## 8. 一分钟自测

1. 公共接口为什么不应要求传 argparse.Namespace？
2. frozen 对象里为什么仍可能有共享列表？
3. 先筛选再校验会隐藏什么？
4. 空选择与空输入分别怎样保留范围？
5. 生成器为什么未必是常数内存方案？
6. 取消后正在执行的线程由谁收尾？
7. 报告失败时怎样保护旧内容和其他文件？
8. 可编辑安装通过为什么仍要测 wheel？
9. 干净安装要排除哪些源码来源干扰？
10. CI、格式版本、发行版本分别意味着什么？
