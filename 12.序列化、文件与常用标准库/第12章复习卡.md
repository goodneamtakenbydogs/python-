# 第 12 章复习卡：序列化、文件与常用标准库

学完讲义与实验后使用。先自己解释，再对照；想不起原因时回讲义，不把短句当首次教学。

## 1. 对象、文本与字节

```text
对象 → 序列化格式文本 → 按编码得到字节
字节 → 按编码解码文本 → 按格式解析对象
```

str 按 Unicode 码点组织，bytes 按 0～255 的字节组织。字节数、码点数和屏幕字形数不同。encode 从文本到字节，decode 反向解释；任意二进制不一定是 UTF-8。

ignore 会丢弃，replace 会替换，继续执行不证明原数据保留。utf-8-sig 可处理开头 BOM，编码选择与 JSON 的 ensure_ascii 是两层规则。

## 2. 文件模式与游标

| 接口 | 复述要点 |
|---|---|
| r | 读已有内容，缺失会失败 |
| w | 打开时就截断，尚未 write 也会丢旧内容 |
| a | 追加，不自动补换行 |
| x | 仅允许新建，已有则失败 |
| b / t / + | 字节或文本、附加读写能力，与打开目的分维度 |
| read / readline / readlines | 从当前游标读，后者收集剩余行 |
| tell / seek | 保存与恢复位置；文本标记不等于任意字符下标 |
| truncate | 明确截短，r+ 覆盖不自动删除旧后缀 |

newline=None 可统一换行，newline='' 可保留终止符。业务空白不一定该 strip。StringIO/BytesIO 是内存流，getvalue 取全部内容，read 从当前位置继续。

缓冲、flush、fsync、close、替换可见性和断电持久性不同。用 with 管理关闭，不把文件回收当确定资源协议。

## 3. 大文件与路径

逐行或分块减少预先装入，但单行、保留结果、缓存与上游仍占空间。生成器暂停可持有文件，耗尽、错误和显式 close 都要有责任；返回前退出 with 不能让返回的生成器继续读已关闭流。

Path 不自动创建实体，相对路径按 cwd 解释，PurePath 主要处理路径语法。glob 不保证排序，exists 后状态可变。绝对路径、.. 与链接会影响目标，不用简单字符串前缀代替完整任务约定。

os.environ 值是文本；环境副本的修改不影响父进程。路径协议允许 Path 交给许多库，但不验证存在与权限。

## 4. JSON、pickle 与 CSV

| 格式 | 适用重点 | 不应误认为 |
|---|---|---|
| JSON | 有限结构化数据交换 | 任意 Python 类型、共享身份或通用深拷贝 |
| pickle | 可信 Python 环境中的状态 | 加密或适合不可信输入的安全格式 |
| CSV | 表格字段文本交换 | 自动得到业务类型和完整校验 |

dumps/loads 面向表示，dump/load 面向流。JSON 键与元组可能转换；集合、日期和 bytes 需约定表示。ensure_ascii 改显示转义，文件仍要选编码。默认特殊数值与重复键可能需要额外严格策略。

相邻 dump 不组成记录集合；数组明确包多项，JSONL 按每个物理行一份完整 JSON。解析成功后仍验证字段与类型。

CSV 由解析器处理逗号、引号和字段内换行，文件常用 newline=''。DictReader 不自动拒绝重复表头、缺列、多列；enabled 不能直接 bool，数值还要验证格式与范围。

## 5. 正则的范围与结果

- match 从起点尝试，search 找某处，fullmatch 要求整体满足。
- r 前缀主要处理 Python 字符串层，正则仍有转义。
- Unicode 的数字和单词类不只 ASCII；按协议选字符集。
- 捕获组影响 findall 的结果形态；finditer 提供匹配对象与位置。
- re.escape 用于字面模式，替换字符串另有分组引用规则。
- groupby 是连续分段；它与正则 finditer 一样，都要检查后续是否全部收集。
- 模式回溯可能昂贵，不把正则当任意结构化数据解析器。

## 6. 时间与时区

date 是日期，datetime 是日期时刻，timedelta 是差量，时间戳需要说明起点和秒/毫秒单位。naive 不自动表示 UTC；aware 需要可用偏移。

astimezone 保持同一时刻，replace 改标签不自动换算。转换可跨日，要保留所需小数秒。不同来源先明确口径，不能靠机器默认本地时区补全未知信息。

固定偏移不等于地区历史规则。ZoneInfo 依赖地区数据，夏令时可产生跳过或重复的当地时间；求实际经过秒数时先对齐 UTC，不机械把每天当 24 小时。

墙上时间适合记录日期时刻，单调时钟适合耗时差值，二者不能随意互转。测试用固定 aware 输入，不要求当前日期或精确耗时。

## 7. 常用工具与系统交互

Counter 计数，defaultdict 下标缺失可建值但 get 不建，deque 适合两端。partial 绑定调用信息，wraps 保留元信息，缓存需容量、失效与清理。chain/islice/groupby 的惰性不等于全部空间固定，分组还可能共享上游。

random 适合可复现模拟，secrets 用于安全随机需求；token_hex 的字节数转成两倍字符数。测试性质，不记录实际随机凭证。

subprocess 先明确可执行程序和 argv，文本输入输出的编码要一致。cwd 和 env 属于子进程条件，父环境改动用副本。stderr 不必然失败，退出码按程序约定，check 对非零抛错。

run 超时主要处理直接子进程，不证明所有后代停止或副作用撤销。capture_output 收集内存，海量输出需流式策略，手工 wait 不消费满管道可能卡住。

临时目录由上下文清理；Windows 打开的文件句柄可能影响再开、删除和替换。gzip 压缩流，ZIP 组织命名成员，压缩不等于加密；外来包需明确允许路径与资源范围。

## 8. 参数与报告提交

argparse 的 type 负责转换，choices 约束允许值，default 给缺省，store_true 表示开关；int 不自动保证正值，type=bool 不适合文字真假。测试传明确 argv 并接收 SystemExit，不使用内核启动参数。

报告先写同目录唯一临时文件，完成并关闭后 os.replace，失败清理临时文件并保留旧目标。替换成功是提交点；多文件事务、并发写入与断电持久性要分别设计。
