这是我的个人 **Vibe Learning** 仓库，用于系统学习 Python 基础、运行机制与面试知识。

当前目标岗位是**测试开发**。前 12 章学习 Python 通用基础，后四章按测试开发岗位需要组织内容。

资料面向已经能用 Python 写程序、但还没有系统学习计算机基础的学习者。学习时先理解概念和执行过程，再通过代码实验验证，最后练习用自己的话回答问题。

## 每章怎样学习

每章包含学习单、完整讲义、代码实验 Notebook、检查器、面试题、参考回答和复习卡。第 1、2 章另有拓展讲义。

推荐顺序：

1. 阅读学习单，明确本章范围和完成标准。
2. 阅读完整讲义，理解术语、例子和执行过程。
3. 打开 Notebook，先预测再运行，逐题做即时检查并解释原因。
4. 闭卷回答面试题，再对照参考回答。
5. 用复习卡回忆，把实际薄弱点记入错题记录。

Notebook 中可能保留个人探索代码和运行记录。需要自己练习时，可以先复制一份 Notebook。检查器核对客观行为，不能代替原因解释与口头复述。

## 运行代码实验

项目偏好 Python 3.12，具体实现和版本限制以各章说明为准。环境配置记录在 `.python-version`、`pyproject.toml` 和 `uv.lock` 中。

安装 [uv](https://docs.astral.sh/uv/getting-started/installation/) 后，在仓库目录执行：

```text
uv sync --group dev
uv run jupyter lab
```

在 Jupyter 中进入相应章节目录，打开该章的 `.ipynb` 文件，选择项目对应的 Python 内核。每题完成后运行紧随其后的检查单元格。

各章检查器需要 Notebook 中的实验记录或实现，不是直接运行脚本就能验证整章学习。示例、输出和行为若依赖 CPython 或特定版本，讲义会注明相应范围。
