# 第 1 章：Python 基础语法与对象模型

## 1. 为什么基础语法还要重新学

你已经可以写一些 Python 代码，这一章并不是让你重新背一遍语法格式。面试更关心的是：一段看似简单的代码为什么会得到这个结果。正文使用的重要术语会在第一次真正需要时解释，不要求你预先知道它们。

例如：

```python
first = [10, 20]
second = first
second.append(30)

print(first)
```

对象可以先理解为程序执行过程中处理的一份数据实体，列表和整数都是对象。类型表示对象属于哪一类以及支持哪些基本行为。`first`、`second` 是代码中的名字，名字让程序能够找到对象；名字与对象之间建立的关联常称为绑定或引用。标题中的**对象模型**就是 Python 关于对象、类型、名字、引用和操作怎样共同工作的基本规则。第 3 节会用对象图完整解释这些关系。

先用这几行代码解释本章会反复使用的几个词：

- `[10, 20]` 创建一个**列表**。列表可以按顺序组织多个对象。
- 列表中的 `10` 和 `20` 称为**元素**，也就是被列表组织起来的对象。
- 能组织零个或多个元素的对象，通常称为**容器**。按照本章的对象模型，可以把容器理解为保存和组织元素对象的引用，放入容器不表示自动为每个元素建立独立副本。本章常见容器包括列表 `list`、元组 `tuple`、字典 `dict` 和集合 `set`。字典按“键到值”的关系保存数据，键用于查找对应值；集合主要保存不重复元素。
- `second.append(30)` 中的 `append` 是列表提供的**方法**，用于把元素加入列表末尾。
- `print(first)` 中的 `print` 是 Python 提供的内置**函数**，使用括号表示调用，括号里的 `first` 是这次调用提供的实参。

函数可以暂时理解为“一段可以被调用的有名字行为”。函数定义中接收输入的名字称为形参，调用时提供的表达式和对象称为实参，日常交流中也常统称参数；函数调用结束后交还给调用位置的结果称为返回值。方法是通过 `对象.方法名(...)` 使用、与某类对象关联的函数式行为。点号 `.` 用于访问对象的**属性**，属性是对象暴露的数据或行为，方法是一种可以调用的属性。类可以先理解为“定义一类对象共同类型和行为的结构”，按照某个类建立的具体对象称为该类的实例。函数、调用、参数和返回值将在第 3 章完整学习；类、实例、属性和方法的对象模型将在第 6 章完整学习。

本章还会使用**序列**这个词。序列是按先后位置组织元素、通常可以用整数下标访问的一类对象，例如字符串、列表和元组。序列属于本章所说的容器家族，但并非所有容器都有位置顺序：字典主要按键访问，集合主要表示不重复元素。

输出是：

```text
[10, 20, 30]
```

如果把变量理解成一个独立装值的盒子，就很容易以为 `second` 得到了一份互不影响的列表副本。但 Python 在这里做的是：让两个名字指向同一个列表对象。因此，通过任意一个名字修改该对象，另一个名字再次访问时都会看到变化。

本章将从这个现象出发，建立下面这条主线：

```text
写下的代码如何被执行
→ 名字如何指向对象
→ 对象为什么有身份、类型和值
→ 赋值和修改为什么不同
→ 基础语法如何利用这些规则工作
```

理解这条主线以后，后续学习容器、实参与形参绑定、嵌套对象复制、类与实例以及对象生命周期时，就不需要分别死记大量特殊情况。

## 2. Python 代码是怎样运行的

### 2.1 Python 语言与 CPython 实现

`Python` 首先是一门语言：它规定代码怎样书写，以及程序应当表现出什么行为。

程序员写在 `.py` 文件或 Notebook 单元格中的文本称为**源代码**。Notebook 是由 Markdown 说明单元格、代码单元格和运行输出等部分组成的交互式文档。程序真正开始执行以后所处的阶段和环境通常称为**运行时**。例如“运行时类型错误”表示代码已经开始执行，执行到相关操作时才发现类型不符合要求。

要真正运行 Python 代码，还需要一个 Python **实现**，也就是遵循 Python 语言规则并负责执行代码的软件系统。最常见的实现叫 `CPython`，它主要使用 C 语言编写。从 Python 官方网站安装的常规 Python，通常就是 CPython。

此外还有 PyPy、Jython 等其他实现。它们都努力遵守 Python 语言规则，但内部执行方式可能不同。

因此，本章会明确区分两类结论：

- **语言规则**：正常 Python 程序可以依赖的行为。
- **CPython 实现细节**：有助于理解常见实现，但业务代码不应把它当作所有 Python 实现都保证的规则。

例如，“`==` 用于比较值，`is` 用于比较是否为同一对象”是语言层面的规则；“某些小整数对象可能被 CPython 复用”则是实现细节。

### 2.2 CPython 的源码编译与字节码执行

人们常说 Python 是解释型语言。这句话适合表达“通常不需要像 C 那样，先由开发者显式编译出独立机器码程序”，但它不是完整的执行过程。

解释器可以先理解为读取某种代码表示并按规则执行它的软件。现实实现可以同时包含解析、编译和解释等步骤，所以“解释”和“编译”并不总是互相排斥。

以 CPython 为例，过程可以先建立这样的直觉：

```text
Python 源代码
→ 解析语法
→ 编译成字节码
→ Python 虚拟机执行字节码
```

- **解析语法**：检查代码能否按照 Python 语法组成有效结构。
- **编译**：把一种代码表示转换成另一种更适合后续执行的表示；它不只表示生成独立机器码程序。
- **机器码**：计算机处理器能够直接执行的底层指令表示。
- **字节码**：CPython 虚拟机能够理解的中间指令。
- **虚拟机**：由软件实现的执行引擎，它读取并执行这些中间指令。

字节码是供 Python 虚拟机执行的一组中间指令，不是直接给计算机处理器执行的普通机器码。CPython 可能**缓存**部分字节码，也就是保存已经生成的结果供后续复用，所以“解释型”也不代表“完全不编译”。

现阶段不需要记忆具体字节码指令。面试中更重要的是避免两个过度简化的说法：

- 不要说 Python 永远逐行读取、逐行执行而完全没有编译过程。
- 不要把 CPython 的内部实现说成 Python 语言唯一可能的实现。

### 2.3 跨平台是什么意思

同一份遵守 Python 语言规则的源代码，通常可以交给不同操作系统上的 Python 实现运行，这就是人们所说的跨平台。它并不表示任何 Python 程序都能不加修改地在所有环境运行。

如果代码依赖某个操作系统独有的路径格式、命令、外部程序或硬件能力，仍然需要进行平台适配。这里的**依赖**是当前程序为了工作而需要的其他软件、库或环境；**系统接口**是操作系统向程序提供的文件、进程、网络等能力。更准确地说，Python 为跨平台运行提供了良好基础，具体程序仍取决于它使用的依赖和系统接口。

### 2.4 缩进与代码块

Python 使用缩进表示代码块：

```python
temperature = 31

if temperature > 30:
    message = "hot"
    print(message)

print("finished")
```

两个缩进的语句属于 `if` 代码块，最后一行不属于。缩进不一致可能产生 `IndentationError`，也就是与缩进结构有关的语法错误；即使没有立即报错，也可能形成与预期不同的代码结构。常见错误名称会在 2.7 节统一解释。

通常使用 4 个空格缩进。不要在同一项目中混用制表符和空格。

### 2.5 名字、关键字和注释

变量名、函数名和类名都属于**标识符**，也就是程序员为对象和代码结构选择的名称。标识符可以由字母、数字和下划线组成，但不能以数字开头，也不能占用**关键字**。关键字是 Python 语法保留并赋予特殊作用的单词，例如 `if`、`for`、`class` 和 `return`，不能再拿来当普通名字：

```python
student_count = 30       # 合法
_cached_result = None    # 合法
# 2students = 30         # 非法：以数字开头
# class = "A"            # 非法：class 是关键字
```

以 `#` 开始的内容是单行注释。注释应解释原因、约束或不明显的决定，而不是逐字复述代码。

### 2.6 字面量、表达式与语句

阅读资料时还会反复遇到三个基础术语：

- **字面量**：直接写在源代码里的值，例如 `10`、`3.5`、`"hello"`、`True` 和 `None`。
- **表达式**：经过计算会得到一个值的代码，例如 `price * count`、`score >= 60` 和 `len(name)`。
- **语句**：让程序执行一个动作的完整代码单位，例如赋值语句 `total = price * count`、`if` 语句和 `for` 语句。

观察下面这行代码：

```python
total = 20 * 3
```

其中 `20` 和 `3` 是字面量，`20 * 3` 是表达式，整行是赋值语句。Python 会先计算右侧表达式得到对象，再把左侧名字绑定到该对象。

有时语法要求必须写一个代码块，但暂时没有动作需要执行，可以使用空语句 `pass`：

```python
total = 60

if total > 50:
    pass
```

`pass` 不会跳出循环，也不会结束函数；它只表示“这里暂时不执行任何动作”。

### 2.7 错误与异常名称怎样阅读

程序运行期间用来表示“当前操作无法正常继续”的错误对象称为**异常**。语法错误通常在正常执行前被发现，其他异常通常在执行到相应操作时出现。

资料中的错误名称不是普通输出。例如：

- `SyntaxError`：源代码没有组成合法语法。
- `IndentationError`：缩进没有形成合法代码结构，它是语法错误的一种。
- `TypeError`：当前对象类型或调用方式不支持这项操作。
- `ValueError`：对象类型可以参与操作，但具体值不符合要求。
- `IndexError`：按位置访问序列时，下标超出有效范围。

本章只解释为什么示例会产生这些名称；异常怎样传播和捕获将在第 7 章完整学习。

这一节只建立运行和书写代码所需的最低直觉。接下来进入本章的核心：Python 中的变量究竟是什么。

## 3. 变量、对象、引用与赋值

### 3.1 对象是什么

Python 程序处理的整数、字符串、列表等数据，在运行时都以对象的形式存在。

可以暂时把对象理解成“程序运行期间存在的一份数据实体”。每个对象至少可以从三个角度观察：

- 身份：它是哪一个对象。
- 类型：它支持哪些基本行为。
- 值：它当前表示的内容。

例如，执行下面的代码会创建或取得一个值为 `42` 的整数对象，并让名字 `score` 指向它：

```python
score = 42
```

更准确的示意图是：

```text
名字                 对象

score ───────────→  整数对象 42
```

### 3.2 变量名与对象的绑定关系

在 Python 中，变量名本身不是一个固定类型的盒子。赋值语句将一个名字绑定到一个对象；“绑定”可以理解为建立名字到对象的关联。

```python
item = 10
item = "book"
```

状态变化如下：

```text
第一行之后：item ───→ 整数对象 10

第二行之后：item ───→ 字符串对象 "book"
```

名字 `item` 没有被永久声明为整数类型。第二次赋值让它改为指向另一个对象，这称为**重新绑定**。

原来的整数对象是否立即被销毁，属于对象生命周期和内存管理问题。对象生命周期可以先理解为“对象从创建到最终被回收的过程”，内存管理则负责为对象安排和释放运行所需存储；它们将在第 9 章详细讨论。本章只需知道：重新绑定名字不等于修改原对象。

### 3.3 赋值默认不会复制对象

观察下面的代码：

```python
first = [10, 20]
second = first
```

第二行不会自动创建一个内容相同的新列表，而是让 `second` 也指向 `first` 当前指向的对象：

```text
first  ─┐
        ├────────→ 列表对象 [10, 20]
second ─┘
```

这种多个名字指向同一个对象的情况，常称为别名关系。此时：

```python
first = [10, 20]
second = first

second.append(30)

print(first)   # [10, 20, 30]
print(second)  # [10, 20, 30]
```

`append()` 修改了共同指向的列表对象，并没有重新绑定 `second`。

### 3.4 修改对象与重新绑定名字的区别

继续使用同一个例子：

```python
first = [10, 20]
second = first

second = [90, 100]
```

最后一行不是修改原列表，而是创建一个新列表，再让 `second` 指向它：

```text
first  ─────────→ 列表对象 [10, 20]

second ─────────→ 列表对象 [90, 100]
```

因此：

```python
first = [10, 20]
second = first
second = [90, 100]

print(first)   # [10, 20]
print(second)  # [90, 100]
```

以后遇到“为什么外部数据也变了”“为什么两个变量不再联动”这类问题，先问自己：这一行是在修改原对象，还是在让某个名字重新绑定到新对象？

### 3.5 赋值语句先计算右边，再绑定左边

```python
count = 5
count = count + 1
```

第二行可以拆成：

1. 找到名字 `count` 当前指向的整数对象 `5`。
2. 计算 `5 + 1`，得到整数对象 `6`。
3. 让名字 `count` 改为指向 `6`。

```text
原来：count ───→ 5
计算：5 + 1 ───→ 6
后来：count ───→ 6
```

整数对象 `5` 并没有被修改成 `6`。这为后面理解“不可变对象”做好了准备。

**面试连接：** 对象模型经常不会被直接问成“请背诵绑定的定义”，而是藏在赋值、实参与形参绑定或浅拷贝的代码题里。分析时画出“名字指向哪个对象”，通常比背一句“Python 一切皆对象”更有效。

## 4. 对象的身份、类型和值

### 4.1 身份、类型和值的区别

假设有两本内容完全相同的书：它们的内容可以相同，但仍是两本不同的书。Python 对象也有类似区别。

- **身份（identity）**回答：是不是同一个对象？
- **类型（type）**回答：这个对象属于什么种类、支持哪些操作？
- **值（value）**回答：这个对象所表示的内容是什么？

```python
first = [1, 2]
second = [1, 2]
alias = first
```

引用关系是：

```text
first ─┐
       ├────────→ 列表对象 A：[1, 2]
alias ─┘

second ─────────→ 列表对象 B：[1, 2]
```

对象 A 和对象 B 的值相等，但身份不同；`first` 和 `alias` 指向的则是同一个对象。

### 4.2 `id()`：观察对象身份的标识

`id(object)` 返回一个整数。在对象存活期间，这个整数能够唯一标识该对象。

```python
values = [1, 2]
alias = values

print(id(values))
print(id(alias))
print(id(values) == id(alias))  # True
```

内存地址可以先理解为数据在程序运行内存中的位置标识。在 CPython 中，`id()` 的结果通常与对象的内存地址有关，但 Python 语言只保证它是对象存活期间唯一的身份标识。代码不应通过解释 `id()` 的数值大小来推断对象位置或生命周期。

`id()` 适合用于实验观察，不适合成为大多数业务逻辑的判断依据。

### 4.3 `type()`：查看对象的直接类型

```python
age = 18
name = "Lin"

print(type(age))   # <class 'int'>
print(type(name))  # <class 'str'>
```

输出中的 `class` 表示返回的是一个类对象。当前阶段可以把“类”与“对象的类型定义”联系起来：`int` 类定义整数对象这一类对象的基本行为，`str` 类定义字符串对象的基本行为。类本身在 Python 中也是对象，完整机制将在第 6 章学习。

如果要判断对象的直接类型是否恰好是某个类型，可以比较 `type()`：

```python
age = 18
print(type(age) is int)  # True
```

不过，面向对象程序中还会有**继承**关系。继承可以先理解为：一个新类型在已有类型基础上复用或扩展行为；新类型称为子类，被复用的已有类型称为父类。一个对象可能属于某个子类，同时也应被视为父类的一种。此时通常更适合使用 `isinstance()`。

### 4.4 `isinstance()`：判断是否属于某种类型体系

```python
value = True

print(type(value) is bool)       # True
print(isinstance(value, bool))   # True
print(isinstance(value, int))    # True
```

最后一行会得到 `True`，因为在 Python 的类型体系中，`bool` 是 `int` 的子类。这并不表示所有布尔语义和整数语义都应混用，只说明继承判断包含了这一关系。

`isinstance()` 也可以一次检查多个候选类型：

```python
number = 3.5

print(isinstance(number, (int, float)))  # True
```

现阶段可以这样选择：

- 只是想查看类型：使用 `type(value)`。
- 接受某个类型及其子类：通常使用 `isinstance(value, ExpectedType)`。
- 必须限制为精确类型：才考虑 `type(value) is ExpectedType`。

继承和鸭子类型会在第 6 章系统展开。鸭子类型最低限度可以理解为：使用对象时更关注它是否提供当前需要的行为，而不只关注它声明属于哪个类。

## 5. `==` 与 `is`：值相等不代表对象相同

### 5.1 `==` 的相等比较与 `is` 的身份比较

```python
first = [1, 2]
second = [1, 2]
alias = first

print(first == second)  # True
print(first is second)  # False
print(first is alias)   # True
```

- `first == second` 比较两个对象的值是否相等。
- `first is second` 会先取得两个操作数对应的对象，再比较它们是否具有相同身份。在这个例子中，也就是检查两个名字是否指向同一个对象。

这里的“比较值”不是解释器对所有类型都使用一套写死的内容比较。`==` 会请求对象所属类型提供它的**相等性规则**：整数按数值比较，字符串按字符内容比较，列表按对应元素比较；自定义类型也可以定义自己的相等条件。

Python 把“对象怎样参加某类语言操作”的一组约定称为**协议**。协议规定 Python 发起什么操作、对象可以提供什么响应。名称开头和结尾各有两个下划线、由 Python 在特定操作中识别的方法，通常称为**特殊方法**。

相等性协议与特殊方法 `__eq__()` 有关。业务代码通常写 `left == right`，由 Python 负责调用完整协议，而不是直接调用 `left.__eq__(right)`。当前可以先把下面关系理解为近似过程：

```text
left == right
→ Python 请求 left 所属类型判断它是否与 right 相等
→ 这个判断通常与 left.__eq__(right) 对应
```

真实比较协议还要处理对方类型和 `NotImplemented`（表示当前类型无法完成这次比较）等情况，这些内容需要先理解类、实例和特殊方法，将在第 6 章完整学习。本章只需要记住：**`==` 的行为可以由对象类型自定义，而 `is` 的身份判断不能被对象改写。**

示意图再次说明了结果：

```text
first ─┐
       ├────────→ 对象 A：[1, 2]
alias ─┘

second ─────────→ 对象 B：[1, 2]

A 与 B：值相等，身份不同
```

### 5.2 数值和字符串的值比较

有时下面的代码在某个 Python 环境中看起来能工作：

```python
left = 100
right = 100
print(left is right)
```

CPython 可能复用某些整数或字符串对象，因此结果有时是 `True`。但对象复用属于实现优化，不能用来表达“数值是否相等”。

这里的**缓存**可以先理解为保留并复用已经存在的对象或结果，避免重复创建；**字符串驻留**是对某些相同字符串复用同一字符串对象的优化方式。是否复用受实现、版本和代码形式影响，不是普通值比较规则。

正确意图应该写成：

```python
left = 100
right = 100
print(left == right)  # True
```

业务代码不要依赖小整数缓存、字符串驻留等实现细节。即使一段 `is` 比较代码在本机得到预期结果，也不代表写法正确。

### 5.3 `None` 是身份判断的典型场景

`None` 表示“没有值”“尚无结果”或“缺少对象”等语义。它是一个特殊的单例对象，也就是一次运行中使用的是同一个 `None` 对象。

推荐写法：

```python
result = None

if result is None:
    print("no result")
```

判断不是 `None`：

```python
result = 0

if result is not None:
    print(result)
```

这里的 `is not` 是一个完整的身份比较运算符，表示“不是同一个对象”，不是先计算普通逻辑 `not` 再交给 `is`。单独的逻辑运算符 `not` 会在第 8 节首次使用前解释，成员运算符 `not in` 会在第 12 节解释。

从语法上说，`result == None` 可以运行，但不推荐用它判断空缺。因为它会进入相等性协议，结果可能受到 `result` 所属类型的自定义规则影响；`result is None` 则只回答它是不是那个唯一的 `None` 对象。

下面只预览现象，不要求现在掌握 `class` 和 `self` 的写法：

```python
class ClaimsEqualToEverything:
    def __eq__(self, other):
        return True


result = ClaimsEqualToEverything()

print(result == None)  # True：进入了自定义相等性规则
print(result is None)  # False：result 并不是 None 对象
```

在这段预览中，`self` 表示左侧的 `result` 实例，`other` 接收右侧的 `None`；这个特殊方法直接返回 `True`，所以 `==` 得到真。第 6 章会解释为什么实例方法要接收 `self`，本章只观察相等性可以被类型定义。

这不是说所有自定义对象都会得到这个结果，而是说明 `== None` 问错了问题。判断空缺时需要确认对象身份，因此使用：

```python
result = None
print(result is None)      # True
print(result is not None)  # False
```

`__eq__()` 为什么能影响 `==`、应该返回什么，以及它与 `__hash__()` 有什么关系，统一留到第 6 章。

不要因为 `None` 在布尔环境中是假值，就把所有假值都当作没有结果：

```python
result = 0

if not result:
    print("这会执行，但 result 明明是一个有效的 0")
```

如果业务上需要区分 `0`、空字符串和“没有结果”，就应明确使用 `is None`。

**面试连接：** 回答 `is` 与 `==` 的区别时，需要同时说清“固定的身份判断”和“可由类型定义的相等性规则”，并能说明为什么判断 `None` 使用 `is None`。只说“一个比较地址，一个比较内容”不够严谨，因为 Python 语言并未要求所有实现都把身份直接暴露为内存地址，而且“内容比较”也没有体现 `==` 可以被自定义。

## 6. 动态类型与强类型

### 6.1 类型检查时机与隐式转换

“动态类型”和“强类型”不是一组反义词，也不是二选一。它们从两个不同角度描述语言的类型系统：

| 观察维度 | 常见两端 | 主要问题 |
|---|---|---|
| 类型何时确定和检查 | 静态类型 / 动态类型 | 运行前是否基本确定表达式类型，许多类型错误何时暴露 |
| 不同类型如何交互 | 相对强类型 / 相对弱类型 | 语言会多大程度隐式转换或允许绕过类型规则 |

**隐式转换**指代码没有明确调用 `int()`、`str()` 等转换工具，语言却根据上下文自动把一种类型按另一种类型处理；**显式转换**则由程序员在代码中直接写明转换意图。

因此一门语言可以同时是动态类型和强类型。Python 通常就被这样描述。

“强类型/弱类型”没有所有教材都接受的唯一严格定义，更适合表示相对倾向。正式回答时，最好给出具体转换行为，而不是只贴标签。

### 6.2 动态类型：类型属于对象，名字可以重新绑定

```python
value = 10
value = "ten"
```

这段代码允许同一个名字先指向整数，再指向字符串。变量通常不需要预先声明固定类型，这体现了 Python 的动态类型特征。

动态类型不等于“对象没有类型”。恰恰相反，每个对象在运行时都有明确类型：

```python
print(type(10))     # <class 'int'>
print(type("ten"))  # <class 'str'>
```

改变的是名字和对象之间的绑定，而不是把同一个对象从整数变成字符串。

动态类型还意味着许多类型错误要到相关代码真正执行时才暴露：

```python
def combine(left, right):
    return left + right


print(combine(1, 2))        # 3
print(combine("a", "b"))    # ab
# combine(1, "b")          # 执行到这里才抛出 TypeError
```

这不等于 Python 完全不能在运行前检查类型。**静态类型检查工具**会在不真正执行这次业务路径的情况下，根据源代码和类型标注推断可能的类型问题。编辑器可以借助它提前提示，但这种额外分析不会改变普通 Python 运行时仍采用动态类型模型，也不能证明业务逻辑一定正确。

### 6.3 静态类型与类型推断

静态类型语言通常在程序运行前就基本确定变量和表达式的类型，并提前拒绝许多不合法操作。例如 Java 中：

```java
int value = 10;
// value = "ten";  // 编译检查不通过
```

静态类型不等于每个类型都必须由程序员手写。Rust、Go、Java 和 C++ 等语言都能进行不同程度的**类型推断**：编译器根据初始值推断类型，但推断完成后，该名字或表达式仍受静态类型约束。

```rust
let mut value = 10;
// value = "ten";  // 推断为整数后，不能改为字符串
```

所以：

```text
没有显式写类型
≠ 动态类型
```

判断静态还是动态，应观察类型何时确定、错误主要何时检查，而不是只看源码中有没有类型名称。

### 6.4 强类型：不会随意混合不兼容的类型

```python
# print("age: " + 18)  # TypeError：不能直接拼接字符串和整数
```

这会抛出 `TypeError`，因为字符串和整数不能直接相加。Python 不会在这里悄悄把整数自动转换为字符串。

需要显式转换：

```python
print("age: " + str(18))
```

或者使用格式化字符串：

```python
age = 18
print(f"age: {age}")
```

这里的重点是 Python 不替你猜测究竟想做数值加法还是字符串拼接。开发者需要明确表达转换意图。

### 6.5 Python 支持的混合类型运算

Python 允许：

```python
print(1 + 2.5)  # 3.5
print("ha" * 3)  # hahaha
```

这不是随意猜测：Python 明确定义了整数与浮点数的兼容数值运算，也明确定义了字符串乘整数表示重复。强类型不等于“任何不同类型都不能一起出现”，而是操作必须符合这些类型明确支持的规则。

同样，Java 允许字符串与其他值使用 `+` 构造文本，仍通常被归为强类型语言。讨论强弱时应看整体类型规则和隐式转换程度，不能用一个孤立例子下结论。

### 6.6 动态类型与强类型的代码示例

```python
value = 10
value = "hello"  # 合法：名字重新绑定到不同类型对象

# value + 5       # TypeError：str 与 int 不支持直接相加
```

前两行体现动态类型；最后一个不兼容操作体现 Python 较强的类型规则。这两个判断同时成立：

```text
动态：名字可以在运行时改为指向另一种类型的对象
强：当前对象参与操作时，必须遵守其类型定义的规则
```

### 6.7 类型标注与 Python 的运行时类型检查

```python
count: int = 10
count = "ten"
```

`count: int` 中的 `: int` 是**类型标注**，用于记录“这里期望整数”这类接口或代码意图。在普通 Python 运行过程中，类型标注默认不会自动阻止第二次赋值。编辑器和静态类型检查工具可以提前提示问题，但 Python 仍然是动态类型语言。类型标注的保存方式和检查工具将在第 11 章详细学习。

如果希望比较 Python、Java、JavaScript、TypeScript、C、Go、Rust 等语言，并进一步理解 JavaScript 为什么会出现 `1 + "2"` 与 `"5" - 2` 的不同结果，请阅读 [第 1 章拓展讲义](./第1章拓展讲义.md)。主讲义到这里已经包含理解 Python 动态强类型所需的完整核心，拓展讲义负责扩大比较范围。

## 7. 可变对象与不可变对象

### 7.1 可变性描述对象本身

任何名字都可以重新绑定。所谓可变或不可变，描述的是**对象自身的值能否在身份不变的情况下被修改**。

本章开头已经把容器定义为“组织零个或多个元素的对象”。因此说一个容器可变，是说它能否在身份不变时增加、删除、替换元素或改变元素关系；不是说容器里的每个元素都具有相同可变性。

常见分类如下：

| 常见对象 | 可变性 |
|---|---|
| `int`、`float`、`bool`、`complex` | 不可变 |
| `str`、`tuple`、`frozenset` | 不可变 |
| `list`、`dict`、`set` | 可变 |

`frozenset` 可以先理解为“创建后不能增删元素的集合”，它与普通 `set` 的完整差异将在第 2 章学习。

容器的具体行为将在第 2 章展开。这里先掌握可变性对赋值和共享引用的影响。

### 7.2 不可变对象：看似变化，实际是重新绑定

```python
count = 10
before = id(count)

count += 1
after = id(count)

print(count)          # 11
print(before == after)
```

整数对象不能原地改成另一个数值。`count += 1` 得到值为 `11` 的对象，再让 `count` 指向它。不同环境中的具体 `id()` 数值没有意义；实验重点是理解重新绑定。

字符串也是不可变对象：

```python
word = "cat"
# word[0] = "C"  # TypeError

word = "C" + word[1:]
print(word)  # Cat
```

最后一段代码构造了新字符串，然后重新绑定 `word`，没有修改原字符串。

### 7.3 可变对象：可以保持身份并改变内容

```python
numbers = [1, 2]
before = id(numbers)

numbers.append(3)
after = id(numbers)

print(numbers)          # [1, 2, 3]
print(before == after)  # True
```

`append()` 修改列表对象本身，所以对象身份保持不变。若另一个名字也指向这个列表，它会观察到相同变化。

```text
修改前：
numbers ─┐
alias   ─┴────→ [1, 2]

执行 numbers.append(3) 后：
numbers ─┐
alias   ─┴────→ [1, 2, 3]
```

### 7.4 `+=` 的表现取决于对象类型

```python
number = 10
number += 1
```

对于整数，通常产生新对象并重新绑定。

```python
values = [10]
alias = values
values += [20]

print(alias)  # [10, 20]
```

对于列表，`+=` 通常原地扩展原列表，因此 `alias` 也能看到变化。

不要仅凭运算符外观判断是否创建新对象，要结合对象类型及其运算行为。自定义类型还可以定义自己的运算规则，这会在第 6 章解释。

### 7.5 不可变容器不等于内部对象都不可变

元组本身不可变，表示元组不能换掉它保存的元素引用。但是元组可以指向一个可变对象：

```python
record = ("task", [80, 90])
record[1].append(100)

print(record)  # ('task', [80, 90, 100])
```

元组的第二个位置仍然指向原来的列表对象；改变的是列表内部内容，不是元组保存的引用。

```text
元组对象：("task", ─────→ 列表对象 [80, 90])
                                  ↓ append(100)
                            [80, 90, 100]
```

### 7.6 为什么可变性很重要

可变性会影响：

- 多个名字是否会观察到同一次修改。
- 对象能否作为字典键。
- 函数接收对象后能否影响调用方看到的内容。
- 浅拷贝后嵌套数据是否仍然共享。对列表等常见可变容器进行浅拷贝时，通常会建立新的外层容器，但内部对象引用仍可能共享；其他对象的具体复制行为可能不同。后面会用列表对象图展开。
- 并发修改时是否可能发生状态冲突。这里的并发可以先理解为多个任务在重叠时间内访问同一状态，完整模型在第 10 章学习。

其中“能否作为字典键”不能简化成“不可变对象都可以”。哈希值是对象按照自身规则计算出的整数，字典用它快速缩小查找候选范围。字典键真正要求对象**可哈希**，当前可以理解为对象能提供稳定的哈希值，并且相等对象遵守相同哈希值的约束；例如元组本身不可变，但包含列表的元组整体不可哈希，不能作为键。完整原因见 [第 1 章拓展讲义的第 21 节](./第1章拓展讲义.md) 和第 2 章哈希表内容。

这些问题会分别在第 2、3、9 和 10 章继续展开。本章先把“修改对象”和“重新绑定名字”区分清楚。

## 8. `None`、真值与布尔环境

### 8.1 任意对象的真值判断

**布尔环境**是程序需要根据“真或假”作出决定的位置，例如 `if` 的分支条件和 `while` 的继续条件。`if` 和 `while` 会把表达式放进布尔环境中判断。许多对象都能按照真值规则被解释为真或假：

下面的例子会第一次使用逻辑运算符 `not`。`not value` 先取得 `value` 的真值，再返回相反的布尔值，而且结果一定是 `True` 或 `False`：

```python
print(not True)   # False
print(not 0)      # True
print(not "text") # False
print(not [])     # True
```

第 8 节只需要用它表达“不是这个真值”；第 13 节会把 `not` 与 `and`、`or`、短路和优先级放在一起完整讲解。

```python
if [1, 2]:
    print("non-empty list")

if not "":
    print("empty string")
```

常见假值包括：

- `None`
- `False`
- 数值零，如 `0`、`0.0`、`0j`
- 空字符串 `""`
- 空容器，如 `[]`、()`、`{}` 和 `set()`

其他普通对象通常为真。

### 8.2 真值判断与精确状态判断不同

```python
items = []

if not items:
    print("no items")
```

如果只关心容器是否为空，这种写法清晰自然。

但下面的函数返回结果可能有两种不同含义：

- `None`：尚未计算。
- `0`：已经计算，结果确实为零。

此时必须写成：

```python
result = None

if result is None:
    print("not calculated")
```

面试代码题中经常利用 `0`、空字符串和 `None` 都是假值来制造边界错误。判断之前先确认业务语义，而不是机械使用 `if value`。

### 8.3 `bool()` 可以显式观察真值

```python
print(bool(0))       # False
print(bool(-1))      # True
print(bool(""))      # False
print(bool("False")) # True，因为这是非空字符串
```

字符串内容写着 `"False"` 并不会让字符串变成布尔假值。空不空与字符串所表达的自然语言含义是两件事。

## 9. 数字对象与基本运算

### 9.1 常见数字类型

Python 内置的常见数字类型包括：

- `int`：整数，例如 `42`、`-7`。
- `float`：浮点数，例如 `3.14`。
- `bool`：布尔值，只有 `True` 和 `False`。
- `complex`：复数，例如 `2 + 3j`。

算法题最常使用 `int` 和 `float`。Python 的整数通常不受固定 32 位或 64 位范围限制，可按需要扩展精度，但数值越大仍会占用更多内存和计算时间。

### 9.2 `/`、`//` 和 `%`

`+`、`/`、`//`、`%` 这类表示运算规则的符号称为**运算符**；运算符处理的对象称为**操作数**。例如 `7 // 2` 中，`//` 是运算符，`7` 和 `2` 是两个操作数。

```python
print(7 / 2)   # 3.5，普通除法
print(7 // 2)  # 3，向下取整除法
print(7 % 2)   # 1，余数
```

需要特别注意负数：`//` 是向负无穷方向取整，不是简单截掉小数部分。

```python
print(-7 // 2)  # -4
print(-7 % 2)   # 1
```

它们满足关系：

```text
a == (a // b) * b + (a % b)
```

此外：

```python
print(2 ** 3)  # 8，乘方
```

### 9.3 布尔值与整数的关系

```python
print(True + True)   # 2
print(False + 5)     # 5
```

这是因为 `bool` 是 `int` 的子类，`True` 和 `False` 在数值运算中分别表现为 `1` 和 `0`。这种行为有时可用于计数，但代码是否清晰应优先于少写几个字符。

### 9.4 浮点数为什么可能“不精确”

```python
result = 0.1 + 0.2
print(result)         # 常见结果为 0.30000000000000004
print(result == 0.3)  # False
```

计算机通常以二进制表示浮点数，而某些十进制小数无法用有限位二进制精确表示。这与十进制中的 `1 / 3` 无法写成有限小数类似。

比较计算得到的浮点数时，通常应允许一个很小的误差：

```python
import math

print(math.isclose(0.1 + 0.2, 0.3))  # True
```

这里的 `math` 是 Python **标准库**中的模块。标准库是随常规 Python 安装提供的一组现成功能；模块可以先理解为组织一组相关名字和代码的对象。`import math` 取得该模块并把名字 `math` 绑定到它，`math.isclose` 再通过属性访问取得模块中的比较函数。模块和导入机制将在第 8 章完整学习。

金融金额等需要精确十进制语义的场景可能使用标准库模块 `decimal` 中的 `Decimal` 类型：

```python
import decimal

left = decimal.Decimal("0.1")
right = decimal.Decimal("0.2")

print(left + right == decimal.Decimal("0.3"))  # True
```

这里用字符串构造十进制值，是为了避免先把不精确的二进制 `float` 传进去。`Decimal` 也有精度和舍入规则：精度决定计算保留多少有效数字，舍入决定超出部分怎样处理。它还具有性能成本，不代表任何金融计算只换一个类型就自动正确；本章只说明存在需要精确十进制语义时的不同工具选择。

### 9.5 显式类型转换

```python
print(int("42"))       # 42
print(float("3.5"))    # 3.5
print(str(42))          # "42"
print(int(3.9))         # 3，向零截断
```

转换并不总能成功：

```python
# int("3.5")  # ValueError
```

“强类型”不代表不能转换，而是通常要求程序明确表达转换意图。

## 10. 字符串：不可变的字符序列

### 10.1 创建与基本访问

字符串用单引号或双引号都可以：

```python
first_name = "Ada"
last_name = 'Lovelace'
```

字符串是有顺序的字符序列，可以按位置访问。这里的字符可以先理解为字符串中的一个文本单位，例如 `"python"` 中依次是 `"p"`、`"y"` 等字符。Unicode 是为不同语言和符号统一分配字符编码标识的标准体系，完整细节留到第 12 章。位置从 `0` 开始：

```python
word = "python"

print(word[0])   # p
print(word[1])   # y
print(word[-1])  # n
```

负索引从末尾向前计数，`-1` 表示最后一个字符。

越过有效范围会抛出 `IndexError`：

```python
word = "python"
# print(word[10])
```

### 10.2 字符串不能原地修改

```python
word = "python"
# word[0] = "P"  # TypeError
```

如果要得到首字母大写的新字符串，可以调用方法或重新组合：

```python
word = "python"
new_word = word.capitalize()
print(new_word)  # Python
print(word)      # python
```

字符串方法通常返回新字符串，不改变原字符串。

### 10.3 拼接、重复、成员判断和长度

```python
language = "Py" + "thon"
line = "-" * 5

print(language)        # Python
print(line)            # -----
print("th" in language) # True
print(len(language))   # 6
```

反复在循环中使用 `result = result + piece` 可能不断创建新字符串。当片段很多时，通常先收集片段，再使用 `"".join(parts)`。具体容器性能将在第 2 章讨论。

### 10.4 格式化字符串

`f-string` 可以把表达式结果放进字符串：

```python
name = "Ada"
score = 95

message = f"{name} scored {score}"
print(message)
```

它通常比大量字符串拼接更清晰。格式控制还有很多用法，但本章只要求能读写最常见形式。

字符串表示文本；字节数据 `bytes` 表示用于文件、网络等场景的原始字节序列。编码和解码是在文本与字节之间按照某种规则转换。它们不是同一个问题，将在第 12 章系统说明。

## 11. 索引与切片

### 11.1 切片使用左闭右开区间

切片的一般形式是：

```text
sequence[start:stop:step]
```

其中包含 `start` 位置，不包含 `stop` 位置。也就是常说的左闭右开区间 `[start, stop)`。

```python
word = "python"

print(word[1:4])  # yth，对应位置 1、2、3
print(word[:2])   # py
print(word[2:])   # thon
print(word[:])    # python
```

左闭右开的好处之一是，切片长度在常规正向情况下容易计算：`stop - start`。

### 11.2 步长与反向切片

```python
numbers = [0, 1, 2, 3, 4, 5]

print(numbers[::2])   # [0, 2, 4]
print(numbers[::-1])  # [5, 4, 3, 2, 1, 0]
```

步长不能为零。步长为负数时遍历方向反转，此时省略的起止位置也按反向遍历解释。

### 11.3 切片与索引的越界表现不同

```python
word = "python"

print(word[:100])  # python，切片会在边界处停止
# print(word[100]) # IndexError
```

索引要求一个具体位置存在；切片表达一个范围，因此超出边界通常会被截到有效范围。

### 11.4 切片通常创建新的序列对象

```python
original = [1, 2, 3]
copied = original[:]

print(original == copied)  # True
print(original is copied)  # False
```

但这只复制外层序列。若内部元素本身是可变对象，内部对象仍可能共享：

```python
original = [[1], [2]]
copied = original[:]

copied[0].append(99)

print(original)  # [[1, 99], [2]]
print(copied)    # [[1, 99], [2]]
```

状态图如下：

```text
original ─→ 外层列表 A ─┬→ 内层列表 X：[1, 99]
                         └→ 内层列表 Y：[2]

copied   ─→ 外层列表 B ─┬→ 同一个内层列表 X
                         └→ 同一个内层列表 Y
```

这属于浅拷贝：只建立新的外层容器，内部对象引用仍可能共享。深拷贝则尝试递归复制内部对象，使嵌套层级也尽量独立，但它有额外时间、空间和对象语义问题。完整的浅拷贝、深拷贝和对象生命周期将在第 9 章展开。

## 12. 比较、成员、身份与运算优先级

### 12.1 比较运算

常见比较包括：

```python
age = 20

print(age == 20)
print(age != 18)
print(age > 18)
print(age <= 20)
```

Python 支持链式比较：

```python
score = 85

if 0 <= score <= 100:
    print("valid")
```

它可以按照 `0 <= score and score <= 100` 的含义理解。这里的 `and` 表示逻辑“并且”，只有两侧条件都为真时整体才为真；与它对应的 `or` 表示逻辑“或者”，至少一侧为真时整体为真。它们的返回对象和短路规则会在第 13 节完整解释。

链式比较还会保证中间表达式 `score` 只求值一次。遇到函数调用等具有副作用的中间表达式时，这一点比简单文本替换更重要。

### 12.2 成员运算：`in` 与 `not in`

`in` 判断值是否属于容器或序列，`not in` 判断不属于：

```python
word = "python"

print("th" in word)        # True
print("java" not in word)  # True
```

`not in` 应作为一个完整的成员比较运算符阅读：

```text
value not in container
```

下面的写法通常也能按 `not (value in container)` 求值，但不推荐：

```text
not value in container
```

前者直接表达“不属于”，不容易让读者重新分析优先级。

不同容器的成员判断复杂度不同，这将在第 2 章讨论。例如 `value in list` 和 `value in set` 看起来相似，底层代价却可能不同。自定义对象怎样参与成员运算属于第 6 章协议内容。

### 12.3 身份运算：`is` 与 `is not`

`is` 会比较两个操作数求值后得到的对象是否具有相同身份，`is not` 则判断它们不是同一个对象：

```text
if result is not None:
    print(result)
```

`is not` 同样应作为完整的身份比较运算符阅读，不要拆成 `is (not ...)`。不要把 `is` 当成 `==` 的更快版本，它们回答的不是同一个问题。

### 12.4 什么是运算优先级

一个表达式同时包含多种运算符时，**运算优先级**决定在没有额外括号的情况下，表达式先怎样分组。

```python
result = 2 + 3 * 4
```

乘法优先级高于加法，所以分组是：

```python
result = 2 + (3 * 4)
```

结果为 `14`，不是 `20`。括号可以显式改变分组：

```python
result = (2 + 3) * 4  # 20
```

### 12.5 常用运算符的优先级

表格最后的条件表达式写成 `yes if condition else no`，会根据 `condition` 的真值只选择并计算一个结果分支，第 14.3 节会结合条件语句完整解释。

下面只列第 1 章已经使用的常见运算，由高到低排列：

| 优先级 | 运算 | 示例 |
|---:|---|---|
| 1，最高 | 括号、函数调用、索引、属性访问 | `(a + b)`、`f()`、`items[0]`、`obj.name` |
| 2 | 乘方 | `2 ** 3` |
| 3 | 一元正负号 | `-number`、`+number` |
| 4 | 乘、除、整除、取余 | `*`、`/`、`//`、`%` |
| 5 | 加、减 | `+`、`-` |
| 6 | 比较、成员、身份 | `<`、`==`、`in`、`not in`、`is`、`is not` |
| 7 | 逻辑非 | `not` |
| 8 | 逻辑与 | `and` |
| 9 | 逻辑或 | `or` |
| 10，最低 | 条件表达式 | `yes if condition else no` |

乘方比一元负号结合得更紧：

```python
print(-2 ** 2)    # -4，相当于 -(2 ** 2)
print((-2) ** 2)  # 4
```

乘方右侧允许直接出现一元正负号，所以还有一个需要单独记住的方向差异：

```python
print(2 ** -1)  # 0.5，相当于 2 ** (-1)
```

因此“乘方高于一元负号”主要帮助分析 `-2 ** 2` 的左侧情况；有疑问时使用括号明确结构。

大多数同级算术运算从左向右分组：

```python
10 - 3 - 2
# 相当于 (10 - 3) - 2
```

乘方是常见例外，它从右向左分组：

```python
2 ** 3 ** 2
# 相当于 2 ** (3 ** 2)
```

这里的“从左向右或从右向左分组”称为**结合方向**。它仍然是在讨论表达式结构，不等于函数实际调用顺序。

### 12.6 优先级与求值顺序不是一回事

优先级回答“表达式怎样分组”，求值顺序回答“各部分在运行时以什么顺序计算”。

```python
def mark(name, value):
    print(name)
    return value


result = mark("first", 1) + mark("second", 2) * mark("third", 3)
print(result)
```

乘法优先级更高，所以结构是：

```text
mark("first", 1) + (mark("second", 2) * mark("third", 3))
```

但 Python 通常从左到右计算操作数，因此显示顺序是：

```text
first
second
third
7
```

`and`、`or` 和链式比较还会短路，可能根本不计算后面的表达式，所以不能只靠优先级表判断哪些函数一定执行。

链式比较的短路可以这样观察：

```python
def upper_limit():
    print("计算上限")
    return 100


value = -5
result = 0 < value < upper_limit()
print(result)  # False
```

第一个比较 `0 < value` 已经为假，整个比较链不可能成立，因此 `upper_limit()` 不会执行。链式比较还保证中间表达式只求值一次；它不能简单替换成可能重复计算中间表达式的两段代码。

### 12.7 为什么实际代码仍建议使用括号

知道优先级是为了正确阅读代码和应对面试，不是为了故意省略所有括号：

```python
has_permission = True
is_owner = False
is_active = True

can_edit = is_active and (has_permission or is_owner)
```

即使不加括号也能根据规则分析，括号仍能立即表达意图。代码首先是给人阅读的。

## 13. 逻辑运算与短路求值

### 13.1 `not`：反转真值并返回布尔值

`not value` 先取得对象的真值，再返回相反的 `bool`：

```python
print(not True)     # False
print(not False)    # True
print(not 0)        # True
print(not "hello")  # False
print(not [])       # True
print(not [0])      # False
```

`not` 与 `and`、`or` 有一个重要区别：

```text
not：一定返回 True 或 False
and：返回某个操作数
or：返回某个操作数
```

连续两次取反可以把任意对象的真值转换成真正的布尔对象：

```python
print(not not "hello")  # True
print(bool("hello"))     # True，通常更直接
```

### 13.2 `and`：遇到第一个假值停止

`and` 从左到右求值：遇到第一个假值就返回它；如果都是真值，则返回最后一个值。

```python
print(0 and 100)        # 0
print("hello" and 100)  # 100
print([] and "next")    # []
```

它不只是返回 `True` 或 `False`，而是返回参与运算的某个对象。

### 13.3 `or`：遇到第一个真值停止

`or` 从左到右求值：遇到第一个真值就返回它；如果都是假值，则返回最后一个值。

```python
print("" or "default")   # default
print("ready" or "wait") # ready
print(0 or None)          # None
```

### 13.4 `not`、`and`、`or` 的优先级

三者由高到低是：

```text
not
→ and
→ or
```

因此：

```python
print(True or False and False)
```

先按结构理解为：

```python
True or (False and False)
```

结果为 `True`。

比较运算的优先级又高于 `not`：

```python
print(not 1 == 2)
```

结构是：

```python
not (1 == 2)
```

结果为 `True`。虽然语法可以这样写，表达“不相等”时通常直接写 `1 != 2` 更清楚。

`not` 高于 `and`：

```python
not True and False
# 相当于 (not True) and False
```

### 13.5 为什么叫短路

一旦结果已经能够确定，后面的表达式就不会执行：

```python
denominator = 0

if denominator != 0 and 10 / denominator > 2:
    print("large quotient")
```

当第一部分为假时，整个 `and` 不可能为真，所以 `10 / denominator` 不会执行，从而避免除零错误。

`or` 也可以提供默认值：

```python
user_input = ""
display_name = user_input or "anonymous"
print(display_name)  # anonymous
```

但这会把所有假值都替换掉。如果合法输入可能是 `0` 或空字符串，就要明确判断 `None`，不能机械使用 `or`。

### 13.6 综合表达式怎样逐步分析

```python
name = ""
result = name and name.upper() or "UNKNOWN"
```

求值过程：

1. `name` 是空字符串，属于假值。
2. `and` 立即返回空字符串，`name.upper()` 不执行。
3. 空字符串是假值，所以 `or` 继续计算并返回 `"UNKNOWN"`。

这种写法还有一个风险：如果 `name.upper()` 合法返回假值，`or` 仍会改用 `"UNKNOWN"`，所以它不完全等价于所有条件表达式。需要明确二选一时，通常使用：

```python
name = ""
result = name.upper() if name else "UNKNOWN"
print(result)  # UNKNOWN
```

### 13.7 复杂布尔表达式的括号与中间变量

实际项目中，更复杂的条件逻辑通常使用清晰的括号、中间变量或普通 `if`。理解优先级和短路是为了正确读代码、避免不必要操作和保护有前置条件的表达式，不是为了把所有分支挤进一行。

**面试连接：** 常见考法是要求预测表达式的值、类型和函数调用顺序。回答时应分开说明“优先级怎样分组”“操作数怎样求值”“短路在哪里停止”和“最终返回哪个对象”。

## 14. 条件语句：根据状态选择路径

### 14.1 `if`、`elif` 和 `else`

```python
score = 78

if score >= 90:
    level = "excellent"
elif score >= 60:
    level = "passed"
else:
    level = "failed"

print(level)
```

条件从上到下检查，执行第一个为真的分支后，其余同组分支不会再执行。因此条件顺序会影响结果。

如果把 `score >= 60` 放在 `score >= 90` 前面，95 分也会先进入“passed”分支。写条件时通常先处理更具体的情况，再处理更宽泛的情况。

### 14.2 条件判断中的临界值

```python
age = 18

if age >= 18:
    print("adult")
```

`>` 和 `>=` 的差别常常就是一道测试用例是否通过。面对题目时，应把临界值单独列出来验证。

### 14.3 条件表达式

简单的二选一可以写成条件表达式：

```python
age = 18
status = "adult" if age >= 18 else "minor"
print(status)  # adult
```

它适合短小、清晰的赋值。**副作用**是表达式除了产生结果之外，还修改外部可观察状态，例如修改已有列表、写文件或打印内容。若每个分支包含复杂计算或副作用，普通 `if` 通常更容易阅读。函数返回值与副作用的接口设计将在第 3 章学习。

## 15. 循环：重复处理一组数据或一个状态

### 15.1 `for` 遍历可迭代对象

```python
for character in "cat":
    print(character)
```

这里依次得到字符 `"c"`、`"a"`、`"t"`。现阶段可以把**可迭代对象**理解为“能够开始一次逐个取元素过程的对象”，字符串、列表、元组和 `range` 都是常见例子。

真正记录“现在取到哪里、下一次给出什么”的对象称为**迭代器**。`for` 会从可迭代对象取得迭代器，再反复让迭代器提供下一个元素，直到没有更多元素。当前不要求手写这个过程；`iter()`、`next()`、停止信号和完整迭代协议将在第 5 章系统学习。

### 15.2 `range()` 表示整数序列规则

```python
for index in range(3):
    print(index)
```

输出 `0`、`1`、`2`。与切片相似，停止值 `3` 不包含在内。

常见形式：

```text
range(stop)
range(start, stop)
range(start, stop, step)
```

`range()` 在 Python 3 中不会先创建一个装有全部整数的普通列表，而是保存范围规则并按需提供整数。

### 15.3 需要位置和值时使用 `enumerate()`

`enumerate(names)` 每轮会提供一个由“位置、元素”组成的二元素结果。`for index, name in ...` 会把这两个元素分别绑定给 `index` 和 `name`，这种一次把多个元素绑定给多个名字的写法称为解包，第 16 节会完整解释。

```python
names = ["Ada", "Linus", "Guido"]

for index, name in enumerate(names):
    print(index, name)
```

比起手动维护计数器，`enumerate()` 更直接地表达“同时需要位置和值”。还可以指定起始编号：

```python
names = ["Ada", "Linus", "Guido"]

for number, name in enumerate(names, start=1):
    print(number, name)
```

### 15.4 并行遍历使用 `zip()`

`zip(names, scores)` 每轮会把两边当前位置的元素组成一个二元素结果，循环中的 `name, score` 使用同样的解包规则取得这两个元素。

```python
names = ["Ada", "Linus"]
scores = [95, 88]

for name, score in zip(names, scores):
    print(name, score)
```

默认情况下，`zip()` 在最短输入耗尽时停止：

```python
print(list(zip([1, 2, 3], ["a", "b"])))
# [(1, 'a'), (2, 'b')]
```

如果长度不一致代表数据错误，就不能无意识地依赖这种截断行为。Python 3.10 及之后可以使用：

```python
names = ["Ada", "Linus"]
scores = [95, 88]

pairs = list(zip(names, scores, strict=True))
print(pairs)  # [('Ada', 95), ('Linus', 88)]
```

`zip()` 按需提供结果，创建 `zip` 对象时不会立即遍历全部输入。这里使用 `list()` 消费完整结果，因此 `strict=True` 能在消费过程中检查各输入是否同时耗尽；长度不一致时会抛出 `ValueError`。较旧版本需要自行校验长度。

### 15.5 `while` 根据条件维持循环

```python
remaining = 3

while remaining > 0:
    print(remaining)
    remaining -= 1
```

`while` 适合“不知道准确次数，但知道继续条件”的场景。必须确保循环状态有机会变化，否则可能形成无限循环。

### 15.6 `break` 与 `continue`

```python
numbers = [3, -1, 5, 0, 8]

for number in numbers:
    if number < 0:
        continue
    if number == 0:
        break
    print(number)
```

- `continue` 跳过本轮剩余语句，进入下一轮。
- `break` 立即结束当前这一层循环。

如果有嵌套循环，`break` 只结束它直接所在的那一层。

### 15.7 循环的 `else`

Python 的 `for` 和 `while` 可以带 `else`。它的准确含义是：循环没有被 `break` 中断时执行。

```python
target = 7
numbers = [1, 3, 5]

for number in numbers:
    if number == target:
        print("found")
        break
else:
    print("not found")
```

即使循环一次也没执行，只要没有遇到 `break`，`else` 也会执行。

它不是“循环条件为假时才执行”这么简单，因为自然遍历结束与 `break` 结束的区别才是关键。若团队不熟悉这种语法，也可以使用标志变量或封装成函数，但面试时应能解释其行为。

## 16. 解包、多变量赋值与交换

### 16.1 序列解包

```python
point = (3, 5)
x_coordinate, y_coordinate = point

print(x_coordinate)  # 3
print(y_coordinate)  # 5
```

右侧提供两个元素，左侧提供两个名字，元素按位置绑定。如果数量不匹配，通常会抛出 `ValueError`。

### 16.2 星号收集剩余元素

```python
first, *middle, last = [10, 20, 30, 40, 50]

print(first)   # 10
print(middle)  # [20, 30, 40]
print(last)    # 50
```

一个解包层级中只能有一个带星号的目标。它会把剩余元素收集为列表。

### 16.3 多变量赋值先计算整个右侧

```python
left = 10
right = 20

left, right = right, left
```

可以理解为：先取得右侧的旧 `right` 和旧 `left`，再分别绑定到左侧名字。因此不需要额外临时变量。

```text
赋值前：left → 10，right → 20
右侧结果：(20, 10)
赋值后：left → 20，right → 10
```

同样的规则解释了：

```python
first = second = []
```

这不是创建两个列表，而是让两个名字绑定到同一个列表对象：

```text
first  ─┐
        ├────────→ 同一个空列表
second ─┘
```

如果需要两个独立列表，应分别创建：

```python
first = []
second = []
```

## 17. 推导式：从已有数据构造新容器

### 17.1 从普通循环到列表推导式

普通写法：

```python
squares = []

for number in range(5):
    squares.append(number * number)
```

列表推导式：

```python
squares = [number * number for number in range(5)]
```

两者都得到：

```text
[0, 1, 4, 9, 16]
```

阅读顺序可以拆成：

```text
对 range(5) 中的每个 number
→ 计算 number * number
→ 收集到新列表
```

### 17.2 加入筛选条件

```python
even_squares = [
    number * number
    for number in range(10)
    if number % 2 == 0
]
```

先判断 `number % 2 == 0`，只有满足条件的元素才参与结果表达式。

### 17.3 字典推导式与集合推导式

```python
square_by_number = {
    number: number * number
    for number in range(4)
}

lengths = {
    len(word)
    for word in ["a", "to", "tea", "cat"]
}
```

集合会去除重复值，因此 `lengths` 中长度 `3` 只出现一次。字典与集合的完整规则和复杂度将在第 2 章学习。

### 17.4 推导式与普通循环的选择

适合推导式的情况：

- 从一组数据清晰地映射出新值。
- 只有简单筛选条件。
- 表达式没有难以理解的副作用。

如果出现多层嵌套、大量条件或修改外部状态，普通循环通常更清晰：

```text
results = []

for record in records:
    if not record.is_valid:
        continue
    normalized = normalize(record)
    results.append(normalized)
```

不要为了展示语法熟练度，把需要逐步解释的逻辑压成一行。

### 17.5 推导式中的名字作用域

**作用域**规定一个名字在哪些代码位置可以被读取，以及读取时从哪里寻找绑定。`LEGB` 是四层名字查找顺序的缩写：Local 表示当前局部，Enclosing 表示外层函数，Global 表示模块全局，Built-in 表示 Python 内置作用域。第 1 章这里只观察推导式循环变量是否影响外部同名名字，完整规则将在第 3 章学习。

在当前主流 Python 3 中，推导式内部的循环变量不会像普通 `for` 循环那样泄露到外层作用域：

```python
number = 100
squares = [number * number for number in range(3)]

print(number)  # 100
```

这是 Python 3 的语言行为。阅读非常旧的 Python 2 资料时可能看到不同结论，但不应把旧版本行为用于当前代码。

## 18. 常见基础陷阱

### 18.1 `[[]] * 3` 复制的是引用

```python
rows = [[]] * 3
rows[0].append("x")

print(rows)  # [['x'], ['x'], ['x']]
```

`* 3` 创建了三个位置，但三个位置都指向同一个内部列表：

```text
rows[0] ─┐
rows[1] ─┼────────→ 同一个内部列表 ["x"]
rows[2] ─┘
```

需要独立内部列表时，可以每次创建新对象：

```python
rows = [[] for _ in range(3)]
```

这不是“列表乘法坏了”，而是要理解被重复的是对象引用。

### 18.2 对象缓存对 `is` 结果的影响

```python
first = 100
second = 100

# 不要用 first is second 判断数值相等
```

普通值比较使用 `==`。对象缓存和复用属于实现细节。

### 18.3 `if value` 会合并多种假值

```python
value = 0

if not value:
    print("这里不能证明 value is None")
```

若不同假值具有不同业务意义，应写精确条件。

### 18.4 浮点结果不能总用精确相等

```python
import math

actual = 0.1 + 0.2
expected = 0.3

print(math.isclose(actual, expected))
```

是否允许误差以及误差多大取决于业务，不存在适用于所有场景的固定阈值。

### 18.5 切片复制不是深拷贝

```python
original = [[1], [2]]
copied = original[:]

copied[0].append(3)
print(original)  # [[1, 3], [2]]
```

外层列表身份不同，内部列表仍然共享。不要只看最外层的 `is` 结果。

### 18.6 `not` 与 `and`、`or` 的返回规则不同

```python
print(not [])           # True
print([] or [1])       # [1]
print("ready" and 5)   # 5
```

`not` 一定返回布尔值，`and` 和 `or` 返回被选中的操作数。只有在明确需要把某个普通对象的真值转换成布尔对象时，才使用 `bool(expression)`。

### 18.7 循环变量在普通 `for` 后仍然存在

```python
for index in range(3):
    pass

print(index)  # 2
```

普通 `for` 循环不会创建独立作用域。推导式在当前 Python 3 中则有自己的作用域。更完整的 LEGB 作用域规则将在第 3 章讲解。

### 18.8 变量名对内置名称的遮蔽

```python
# 不推荐
list = [1, 2, 3]

# 后面再调用 list(...) 时，名字已经指向上面的列表对象
```

同类高风险名字还有 `str`、`dict`、`set`、`sum`、`max` 和 `id`。使用 `numbers`、`total`、`maximum` 等能表达含义的名字。

## 19. 语言规则与 CPython 细节的边界

基础面试中，一个常见失分点是把自己在 CPython 中观察到的现象说成 Python 永远保证的规则。

| 结论 | 性质 | 代码是否可以依赖 |
|---|---|---|
| `is` 判断是否为同一对象 | Python 语言规则 | 可以 |
| `==` 用于值相等比较 | Python 语言规则 | 可以 |
| 字符串和整数对象不可变 | Python 语言规则 | 可以 |
| `None` 是单例，推荐用 `is None` | Python 语言规则与编码惯例 | 可以 |
| `id()` 在对象存活期间唯一 | Python 语言规则 | 可以，但很少需要用于业务逻辑 |
| CPython 的 `id()` 通常对应内存地址 | CPython 实现细节 | 不应依赖 |
| 某些小整数对象会被复用 | 常见实现优化 | 不应依赖 |
| 某些字符串可能被驻留复用 | 常见实现优化 | 不应依赖 |
| CPython 先把源码编译成字节码再由虚拟机执行 | CPython 执行方式 | 可用于解释 CPython，不代表所有实现完全相同 |

稳妥的面试表达通常具有这样的结构：

```text
先说 Python 语言保证什么
→ 再补充 CPython 通常怎样实现
→ 最后说明实际代码能不能依赖这个细节
```

## 20. 基础代码风格与 PEP 8

`PEP` 是 Python Enhancement Proposal 的缩写，表示用于提出和记录 Python 改进、规范或指导信息的一类正式文档。`PEP 8` 是其中由 Python 社区广泛采用的代码风格指南。它不会决定程序算法是否正确，但清晰、一致的代码更容易审查、测试和维护。

本阶段先形成以下习惯：

### 20.1 使用表达含义的名字

```python
# 不清楚
nums = [1, 2, 3]
x = 0
for v in nums:
    x += v

# 更清楚
numbers = [1, 2, 3]
total = 0
for number in numbers:
    total += number
```

算法题中短小的索引 `i`、`j` 并非绝对错误，但状态复杂时应使用 `left`、`right`、`index`、`current_total` 等名称。

### 20.2 保持一致的缩进和空格

```python
left = 2
right = 3
limit = 4
result = left + right

if result > limit:
    print(result)
```

通常使用 4 个空格缩进，并在二元运算符两侧保留空格。

### 20.3 条件表达式与 `if` 的选择

```python
# 不推荐：步骤不易观察
value = 5
result = value * 2 if value > 0 else 0
```

这一行本身还算简单；如果条件和表达式继续增长，就应改为普通 `if`，让分支和中间状态清楚可见。

### 20.4 代码风格要求与语法规则的区别

不符合 PEP 8 通常不会使 Python 拒绝运行。语言语法规定“能不能运行”，风格指南帮助团队统一“怎样写得清楚”。面试手写代码时，清晰命名、合理缩进和可解释的步骤通常比追求最短代码更重要。

## 21. 如何分析一段基础 Python 代码

遇到输出判断或找错题时，可以按以下顺序分析。

### 第一步：列出创建或取得了哪些对象

```python
first = [1, 2]
second = first
```

这里核心是一个列表对象，不是两份列表。

### 第二步：画出名字与对象的绑定

```text
first  ─┐
second ─┴────→ [1, 2]
```

### 第三步：判断每个操作是修改还是重新绑定

```text
second.append(3)  # 修改共同对象
second = [9]      # 重新绑定 second
```

### 第四步：遇到条件时计算真值和短路顺序

```text
if second and second[0] > 0:
    ...
```

先判断 `second` 是否为真；只有为真时才读取 `second[0]`。

### 第五步：确认是否依赖实现细节

若推理使用了“两个整数一定是同一对象”“`id()` 一定是内存地址”等说法，就应停下来改用语言保证的规则。

用这五步分析下面的代码：

```python
first = [0]
second = first

if second and second[0] == 0:
    second += [1]

second = [9]
```

状态依次是：

```text
1. first、second → 同一个 [0]
2. second 为真，second[0] == 0 为真
3. 列表 += 原地扩展，共同对象变为 [0, 1]
4. second 重新绑定到新列表 [9]

最终：first → [0, 1]
      second → [9]
```

这一个例子同时连接了对象、引用、可变性、真值、短路和重新绑定。它也说明，这些知识点不是互不相关的八股结论，而是同一套运行模型在不同语法中的表现。

## 23. 本章总结

本章最重要的不是记住所有语法，而是形成一套稳定的运行直觉：

1. Python 是一门语言，CPython 是它最常见的实现；语言规则和实现细节必须区分。
2. 变量名通过赋值绑定到对象，赋值通常不会自动复制对象。
3. 对象具有身份、类型和值；`id()`、`type()` 和 `isinstance()`观察的角度不同。
4. `==` 使用对象类型提供的相等性规则，`is` 固定比较身份；普通数值和字符串用 `==`，判断单例 `None` 用 `is None`，因为 `== None` 会进入可自定义协议。
5. 静态/动态与强/弱是两个维度；类型推断不等于动态类型。Python 的名字可以绑定不同类型对象，但不兼容类型通常不会被随意隐式混用。
6. 可变性属于对象，不属于变量；必须区分修改对象与重新绑定名字。
7. `if` 和 `while` 使用真值规则，`None`、零和空容器虽然都为假，但业务含义可能不同。
8. `not` 反转真值并返回 `bool`；`and` 和 `or` 会短路并返回某个操作数。优先级决定分组，不等于实际求值顺序。
9. 索引取得具体位置，切片表示左闭右开的范围；切片复制外层不等于深拷贝。
10. 解包、推导式、`enumerate()` 和 `zip()` 应用于表达清楚的数据处理，而不是为了追求短代码。
11. 遇到基础代码题时，画出名字与对象的关系，再逐行判断修改、重新绑定和求值顺序。

当你能够不依赖运行环境，清楚解释“每个名字现在指向哪个对象、这一行修改了什么、为什么这个条件会或不会继续求值”时，才算真正掌握了本章的核心。
