# 第 1 章复习卡：Python 基础语法与对象模型

> 本卡用于学完后的快速回忆。遇到说不清楚的概念，应返回完整讲义和代码实验，而不是把这里的短句当作首次教学。

## 1. Python 对象模型与代码执行流程

```text
源代码按语法组成表达式和语句
→ 名字通过赋值关联到对象
→ 对象具有身份、类型和值
→ 操作可能产生新对象，也可能修改原对象
→ 条件和循环根据表达式结果控制执行路径
```

分析短代码时，优先问：

1. 当前有哪些名字？
2. 每个名字指向哪个对象？
3. 这一步是在重新绑定名字，还是修改原对象？
4. 表达式的结果和值是什么？
5. 下一步会执行哪个分支？

## 2. 核心术语

| 术语 | 快速回忆 |
|---|---|
| 名字 | 代码中用于引用对象的标识符 |
| 对象 | Python 运行时处理的数据实体 |
| 引用 | 名字与对象之间的关联关系 |
| 赋值 | 让一个名字关联到某个对象 |
| 元素 | 被容器组织起来的单个对象 |
| 容器 | 能组织零个或多个元素的对象，如列表、元组、字典和集合 |
| 序列 | 按先后位置组织元素、通常可用整数下标访问的一类对象 |
| 函数 | 可以被调用的行为；形参接收输入，调用通过实参提供对象 |
| 方法 | 与某类对象关联、通过 `对象.方法名(...)` 使用的可调用属性 |
| 属性 | 通过点号从对象上访问的数据或行为 |
| 类与实例 | 类定义一类对象的类型和行为，实例是按照该类建立的具体对象 |
| 身份 | 对象“是不是同一个”的属性，可用 `id()` 观察 |
| 类型 | 对象支持哪些操作及其大致行为 |
| 值 | 对象所表示的内容 |
| 可变对象 | 创建后，其内部状态可以发生变化的对象 |
| 不可变对象 | 创建后，其值不能原地改变的对象 |
| 动态类型 | 名字不固定绑定某一种类型，可以在运行时改为指向其他类型对象 |
| 强类型 | 不兼容类型通常不会被随意隐式混合运算 |
| 真值 | 对象放入条件判断时表现为真或假 |
| 短路求值 | 已能确定逻辑结果时，不再计算后续操作数 |
| 运算优先级 | 没有额外括号时，多种运算符先怎样组成表达式 |
| 结合方向 | 相同优先级运算从左向右或从右向左分组 |
| 求值顺序 | 分组确定后，各操作数和子表达式实际按什么顺序计算 |
| 切片 | 按起点、终点和步长取得序列的一部分 |
| 解包 | 将可迭代数据中的元素分别绑定给多个名字 |
| 推导式 | 用紧凑语法根据迭代和条件构造容器 |
| 可迭代对象 | 能开始一次逐个取元素过程的对象 |
| 迭代器 | 记录遍历位置并逐个提供下一元素的对象 |
| 异常 | 运行中表示当前操作无法正常继续的错误对象 |
| 模块与标准库 | 模块组织相关名字和代码；标准库是常规 Python 自带功能集合 |
| 协议 | Python 规定对象怎样参与某类操作的一组约定 |
| 作用域 | 规定名字在哪些位置可见、读取时从哪里寻找绑定 |

## 3. 最容易混淆的对比

### 3.1 `==` 与 `is`

| 比较 | 关注的问题 | 常见用途 |
|---|---|---|
| `a == b` | 两者的值是否相等 | 比较数字、字符串、容器内容等 |
| `a is b` | 两者是否是同一个对象 | 判断 `None`，或确实需要判断对象身份 |

`==` 会使用对象类型提供的相等性规则，这个规则可以由自定义类型通过与 `__eq__()` 有关的协议改变；`is` 的身份判断不能被重载。

记忆边界：不要因为某次运行中两个整数或字符串满足 `is`，就用 `is` 代替值比较。缓存和驻留属于实现细节，不是这种写法的可靠依据。`__eq__()` 的完整规则在第 6 章学习。

### 3.2 `type()` 与 `isinstance()`

| 工具 | 快速回忆 |
|---|---|
| `type(value)` | 观察对象的直接类型，也可以用于严格类型比较 |
| `isinstance(value, SomeType)` | 判断对象是否属于指定类型或其子类，通常更适合面向继承关系的判断 |

### 3.3 重新赋值与原地修改

```python
numbers = [1, 2]
alias = numbers

numbers = [3, 4]       # numbers 改为指向另一个列表
alias.append(5)        # 修改 alias 当前指向的原列表
```

复习重点：名字变了，不等于原对象变了；一个可变对象发生变化，所有仍指向它的名字都能观察到变化。

### 3.4 动态类型与强类型

| 维度 | 常见两端 | 主要问题 |
|---|---|---|
| 类型何时确定和检查 | 静态 / 动态 | 运行前是否基本确定表达式类型，错误主要何时暴露 |
| 类型之间如何交互 | 相对强 / 相对弱 | 隐式转换和绕过类型规则有多宽松 |

- Python 是动态类型：名字可以在运行时指向不同类型的对象。
- Python 的类型规则相对强：不兼容操作通常明确报错，而不是任意转换。
- 二者不是反义关系，Python 可以同时具有这两个特点。
- 类型推断不等于动态类型；Rust、Go、Java 和 C++ 即使省略局部类型名称，推断结果仍受静态约束。
- `int + float` 等明确支持的混合操作不等于语言整体是弱类型。
- 强弱分类没有所有资料统一采用的绝对边界，回答时应给出具体转换行为。

近似比较：

| 语言 | 静态/动态 | 强弱倾向 |
|---|---|---|
| Python | 动态 | 较强 |
| Java | 静态 | 较强 |
| JavaScript | 动态 | 隐式转换宽松 |
| TypeScript | 渐进式静态检查 | 运行时继承 JavaScript |
| Go、Rust | 静态 | 较强或很严格 |
| C、C++ | 静态 | 强弱分类存在争议，转换和底层逃生口较多 |

完整的横向比较和 JavaScript 转换过程见 [第 1 章拓展讲义](./第1章拓展讲义.md)。

### 3.5 可变与不可变

常见初步分类：

- 常见不可变对象：`int`、`float`、`bool`、`complex`、`str`、`tuple`。
- 常见可变对象：`list`、`dict`、`set`。

注意：元组自身不可变，但元组内部可以引用可变对象。更深入的容器共享与复制放在第 2、9 章。

### 3.6 索引与切片

- 索引取得一个位置的元素，越界通常引发 `IndexError`。
- 切片使用半开区间，通常写作 `[start:stop:step]`，包含 `start`，不包含 `stop`。
- 负索引从序列末尾计数。
- 切片得到一段序列，但不等于深拷贝。列表切片通常创建新的外层列表；不可变序列的实现可能复用对象，代码不应依赖切片结果的身份。

## 4. 高频规则

### 4.1 Python 特点与代码结构

- 动态类型和强类型描述不同角度，并不冲突。
- 编译/解释、静态/动态、类型推断和动态分派是不同问题。
- 常见 Python 实现先把源代码转换为可执行的中间形式，再由解释器执行；“解释执行”不等于机械地逐字直接运行源码。
- 跨平台意味着同一份 Python 代码通常可以在不同操作系统运行，但依赖系统接口的代码仍可能需要适配。
- 标识符用于命名，关键字具有语法意义，不能拿来作为普通名字。
- 缩进决定代码块；注释用于解释意图，不参与正常程序结果。

### 4.2 `None`

- `None` 表示“没有值”或“当前无结果”一类状态，不等同于 `0`、`False`、`""` 或 `[]`。
- 判断是否为 `None` 通常写 `value is None` 或 `value is not None`。
- `value == None` 能执行但会进入可自定义的相等性协议，不能精确表达身份判断。

### 4.3 真值与假值

常见假值包括：

```python
None
False
0
0.0
0j
""
[]
()
{}
set()
```

除假值以外的普通对象通常表现为真。自定义对象如何决定真值将在第 6 章继续学习。

### 4.4 `not`、`and` 与 `or`

- `not value` 先取得真值，再返回相反的 `bool`。
- `and` 从左到右求值，遇到假值即可停止；没有遇到假值时得到最后一个操作数。
- `or` 从左到右求值，遇到真值即可停止；没有遇到真值时得到最后一个操作数。
- `not` 一定返回 `True` 或 `False`，`and` 和 `or` 返回被选中的操作数。
- 三者优先级是 `not` 高于 `and`，`and` 高于 `or`。
- 短路会影响右侧表达式是否执行，分析有函数调用或副作用的代码时尤其要注意。

### 4.5 条件与循环

- `if`、`elif`、`else` 按顺序选择一个满足条件的分支。
- `break` 结束当前循环。
- `continue` 跳过当前轮剩余语句，进入下一轮。
- 循环正常结束时可以执行 `else`；通过 `break` 离开时不执行该 `else`。
- 缩进决定代码块，不能只当作排版习惯。

### 4.6 运算符与表达式

- 算术运算产生数值结果，比较运算通常产生布尔结果。
- `in`、`not in` 判断成员关系；`is`、`is not` 判断对象身份。`not in` 和 `is not` 应作为完整比较运算符阅读。
- 常用优先级由高到低：括号/调用/索引/属性、乘方、一元正负、乘除、加减、比较/成员/身份、`not`、`and`、`or`、条件表达式。
- 优先级决定分组，求值顺序决定运行时各部分的计算先后，短路还可能跳过后续部分。
- 代码意图不直观时主动加括号，不靠读者背表猜测。

### 4.7 解包与遍历工具

- 解包时，左侧名字数量通常要与右侧元素数量匹配；带星号目标可以收集剩余元素。
- `range()` 表示整数范围，终点不包含在内。
- `enumerate()` 同时产生位置和元素。
- `zip()` 将多个可迭代对象按位置配对，并在最短输入耗尽时停止。

### 4.8 推导式

- 列表推导式生成列表，集合推导式生成集合，字典推导式生成键值映射。
- 推导式适合单一映射和简单筛选。
- 出现多层复杂条件、状态修改或难以命名的逻辑时，普通循环通常更清楚。

### 4.9 浮点数

- 许多十进制小数无法用有限位二进制浮点数精确表示。
- 计算结果可能存在很小误差，不应把所有浮点计算都当作精确实数运算。
- 需要容差时可考虑 `math.isclose()`；容差如何设置应结合业务含义。

### 4.10 基础代码风格

- 使用 4 个空格缩进并保持层级一致。
- 名字应表达用途，通常使用小写字母和下划线。
- 不要用 `list`、`str`、`sum`、`max` 等常用内置名称作为自己的变量名。
- 清晰优先于炫技式短写法；复杂表达式可拆分或加括号。

## 5. 常见陷阱提醒

1. 把变量想成带固定类型的盒子，因而无法解释重新赋值。
2. 用 `is` 比较数字、字符串或容器的值。
3. 看到 `a == b` 就断定二者是同一个对象。
4. 认为不可变的是名字，而不是对象。
5. 认为元组不可变就意味着其引用的所有内部对象都不能变化。
6. 把所有非空字符串都理解成“逻辑上的真”，忽略字符串内容并不会自动解析为布尔值。
7. 以为 `and`、`or` 一定返回 `True` 或 `False`。
8. 忽略短路，错误判断右侧函数一定会执行。
9. 混淆 `break` 与 `continue`，或者忘记 `break` 会阻止循环 `else` 执行。
10. 忘记切片终点不包含在结果中。
11. 把切片误认为深拷贝。
12. 用 `==` 要求一般浮点计算结果完全精确。
13. 为了简短把多层逻辑塞进推导式，导致代码难以解释。
14. 把 CPython 的小整数缓存或字符串驻留当作 Python 语言必须保证的规则。
15. 使用 `value == None` 判断身份，忽略对象可以自定义相等性规则。
16. 使用了 `not`，却不知道它一定返回布尔值。
17. 把 `not in` 或 `is not` 错误拆成两个互不相关的运算。
18. 把运算优先级误认为函数调用的实际先后顺序。
19. 只按优先级分组，忽略 `and`、`or` 和比较链可能短路。

## 6. 面试回答骨架

回答本章概念题时，可以按下面顺序组织：

```text
一句话结论
→ 概念关注的对象是什么
→ 一个最小代码或关系图
→ 常见误区
→ 语言规则与实现细节的边界
```

代码输出题不要只报结果。应说明每次赋值后名字指向什么、对象是否被修改、条件表达式得到什么，以及因此进入哪个分支。
