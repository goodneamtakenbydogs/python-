# 第 1 章学习单：Python 基础语法与对象模型

## 1. 本章为什么要学

写 Python 时，我们经常会说“创建一个变量”“把一个值放进变量”“修改这个变量”。这些说法便于日常交流，但不足以解释下面这些现象：

- 两个名字为什么可能同时看到同一个列表的变化？
- `==` 为 `True` 时，`is` 为什么仍可能为 `False`？
- 为什么字符串可以读取某个位置，却不能直接修改该位置？
- 为什么 `and` 和 `or` 的结果不一定是 `True` 或 `False`？
- 为什么 `0.1 + 0.2 == 0.3` 可能为 `False`？

本章从名字、对象、引用和赋值开始，建立理解 Python 代码运行行为所需的第一层模型，同时补齐后续章节都会使用的基础语法。

## 2. 学习目标

完成本章后，你应当能够：

1. 区分名字、对象、引用和赋值，不再把变量简单理解成固定类型的盒子。
2. 从身份、类型和值三个角度观察一个对象，并正确使用 `id()`、`type()` 和 `isinstance()`。
3. 区分 `is` 与 `==`，特别是正确判断 `None`。
4. 判断常见对象是否可变，并分析一次操作是在修改原对象还是让名字改为指向另一个对象。
5. 解释 Python 的动态类型与强类型分别指什么。
6. 使用数字、字符串、条件、循环、运算符、索引、切片、解包和推导式编写清晰的基础代码。
7. 分析真值、短路求值、循环 `else`、浮点数比较等容易误判的行为。
8. 在面试中先给出准确结论，再用一个简短例子说明原因和边界。

## 3. 前置知识

开始本章前，只要求你能够：

- 运行一段 Python 3 代码。
- 看懂简单的赋值和函数调用，例如 `score = 80`、`print(score)`。
- 使用列表和字符串完成过基础编程或算法题。
- 知道程序会按照一定顺序执行语句。

不要求你事先理解内存管理、哈希表、函数调用中的实参与形参绑定或面向对象。相关内容会在后续章节系统学习。

## 4. 本章知识点清单

### 4.1 Python 与代码结构

- Python 的动态类型、强类型、解释执行和跨平台特点。
- 源代码、运行时、语言实现、解释器、编译、字节码和虚拟机的最低限度含义。
- 标识符、关键字、注释、缩进与代码块。
- 函数、调用、形参、实参、返回值、方法和属性的最低限度含义。
- 元素、容器、序列、可迭代对象和迭代器的最低限度含义。
- 错误与异常、模块与标准库、协议与特殊方法、作用域等辅助术语的当前所需含义。
- Python 3 基础代码风格和 PEP 8 的作用。

### 4.2 名字与对象

- 名字、对象、引用和赋值之间的关系。
- 对象的身份、类型和值。
- `id()`、`type()` 和 `isinstance()` 的用途。
- 多个名字指向同一个对象时会发生什么。
- 重新赋值与修改原对象的区别。

### 4.3 相等、同一与空值

- `==` 比较的是什么。
- `==` 会使用对象的相等性协议，而且自定义类型可以改变该协议。
- `__eq__()` 只在本章作最低限度预览，完整机制留到第 6 章。
- `is` 比较的是什么。
- `None` 表示什么，以及为什么通常使用 `is None` 判断。
- 为什么不推荐使用 `value == None` 判断空缺状态。
- 为什么不能依赖小整数缓存或字符串驻留来决定是否使用 `is`。

### 4.4 类型与可变性

- 静态/动态与强/弱是描述类型系统的两个不同维度。
- 动态类型与静态类型主要关注类型何时确定和检查。
- 强类型与弱类型主要关注隐式转换和绕过类型规则的宽松程度。
- 类型推断不等于动态类型，类型注解也不会自动把 Python 运行时变成静态类型。
- 强弱分类没有所有资料都统一采用的绝对边界。
- `int`、`float`、`bool`、`complex` 等数字类型。
- 字符串的不可变性。
- 常见可变对象与不可变对象的初步分类。
- “不可变”描述的是对象，而不是名字。

> 本章只建立可变性和共享引用的直觉。浅拷贝、深拷贝、引用计数和垃圾回收将在第 9 章展开；各种容器的性质和复杂度将在第 2 章展开。

### 4.5 表达式与流程控制

- 算术、比较、逻辑、成员和身份运算符。
- `not` 先取得真值再返回相反的 `bool`。
- `and`、`or` 的短路求值及返回操作数规则。
- `not in` 与 `is not` 作为完整比较运算符阅读。
- 当前阶段常用运算符优先级和结合方向。
- 运算优先级与实际求值顺序的区别。
- 理解规则后仍使用括号明确复杂意图。
- 真值与假值规则。
- `if`、`elif`、`else`。
- `for`、`while`、`break`、`continue` 和循环 `else`。

### 4.6 字符串与常用序列语法

- 字符串索引、负索引与切片。
- 切片边界和步长的基本语义。
- 序列解包、多变量赋值与变量交换。
- `range()`、`enumerate()` 和 `zip()` 的基本语义。

### 4.7 简洁表达与数值边界

- 条件表达式。
- 列表、集合和字典推导式的基本写法。
- 什么时候应优先使用普通循环保持清晰。
- 浮点数的二进制表示误差。
- 浮点计算结果的近似比较意识。

## 5. 推荐学习顺序

### 第一步：先建立对象模型

先阅读完整讲义中有关名字、对象、引用和赋值的内容。学习这一部分时，不急着背术语，要能够画出“名字指向对象”的关系，并区分重新赋值与原地修改。

### 第二步：学习身份、类型、值与可变性

继续学习 `id()`、`type()`、`isinstance()`、`is`、`==`、`None` 和可变性。这些概念必须放在同一条理解链中，否则容易只记住零散结论。

### 第三步：补齐基础语法

学习运算符、真值、条件、循环、字符串、切片、解包和推导式。重点不是记住语法外形，而是预测每一步会读取什么、改变什么、产生什么新对象。

### 第四步：按需阅读拓展讲义

如果需要比较其他语言、理解 JavaScript 隐式转换，或继续区分不可变、可哈希与字典键，阅读 `第1章拓展讲义.md`。它是选读材料，不能代替主讲义中的 Python 核心解释。

### 第五步：完成代码实验

每个实验先写下预测，再运行代码，最后解释实际结果。预测错误并不是失败；只有跳过原因分析，才无法形成稳定理解。

### 第六步：闭卷练习面试题

先独立回答，再查看参考回答。对代码输出题，应先逐行分析，不要依赖运行代码猜答案。

### 第七步：使用复习卡回忆

学完后再看复习卡。遮住笔记回答一分钟自测；说不清楚的内容回到完整讲义或对应实验，而不是直接背复习卡上的短句。

## 6. 建议学习时间

主线建议总计 **8～10 小时**；加上类型系统拓展后约为 **9～12 小时**，可拆成 3～4 次完成。

| 学习任务 | 建议时间 |
|---|---:|
| 阅读学习单并建立本章问题意识 | 20 分钟 |
| 学习名字、对象、引用、身份、类型和值 | 2 小时 |
| 学习可变性、`is`、`==`、`None` 和类型特点 | 1.5 小时 |
| 选读类型系统跨语言拓展 | 1～1.5 小时 |
| 学习流程控制、字符串、切片、解包与推导式 | 2 小时 |
| 完成代码实验并记录观察 | 1.5～2 小时 |
| 闭卷回答面试题并对照参考回答 | 1.5 小时 |
| 使用复习卡复盘 | 30 分钟 |

如果你已经熟悉基础语法，可以缩短语法部分，但不要跳过对象模型、可变性、短路求值和浮点误差实验。

## 8. 分层完成标准

### 8.1 知道

达到这一层，意味着你能认出术语并说出基本含义：

- 知道 Python 中赋值会建立名字与对象之间的关系。
- 知道对象可以从身份、类型和值三个角度观察。
- 知道 `is`、`==`、`type()`、`isinstance()` 的基本用途不同。
- 知道可变对象与不可变对象的含义。
- 知道哪些值通常会被当作假值。
- 知道索引、切片、解包、推导式和短路求值是什么。

### 8.2 理解

达到这一层，意味着你能解释“为什么”：

- 能画出两个名字指向同一列表时的关系，并解释修改为什么会被共同观察到。
- 能解释重新赋值为什么不等于修改原对象。
- 能解释值相等不代表是同一个对象。
- 能解释为什么判断 `None` 通常使用 `is None`，而不是只背写法。
- 能解释动态类型与强类型并不矛盾。
- 能解释类型推断为什么不等于动态类型，也能说明强弱类型分类的边界并不绝对。
- 能逐步说明 `and`、`or` 为什么可能不返回布尔值。
- 能解释 `not` 为什么一定返回布尔值，并正确分析它与比较、`and`、`or` 的优先级。
- 能区分运算优先级、结合方向和实际求值顺序。
- 能解释常见浮点比较问题来自表示误差，而不是 Python 随机算错。

### 8.3 会用

达到这一层，意味着你能在代码中正确应用：

- 能选择正确的相等或身份判断方式。
- 能避免把“修改对象”和“给名字重新赋值”混为一谈。
- 能使用索引、切片、解包、`range()`、`enumerate()` 和 `zip()` 处理基础数据。
- 能正确使用条件、循环、`break`、`continue` 和循环 `else`。
- 能在适合时使用简单推导式，在逻辑复杂时改用普通循环。
- 能使用近似比较处理需要容忍误差的浮点结果。
- 能写出命名清晰、缩进正确且不遮蔽常用内置名称的代码。

### 8.4 能回答

达到这一层，意味着你能不看资料完成面试表达：

- 能在 60～90 秒内解释 Python 的变量、对象和引用模型。
- 能先说结论，再比较 `is` 与 `==`，并给出一个恰当例子。
- 能说明动态类型和强类型分别约束什么。
- 能用不同语言的简短例子说明静态/动态与强/弱是两条不同维度。
- 能解释可变与不可变，并指出这一分类描述的是对象。
- 能现场分析一段包含共享引用、短路求值、切片或循环 `else` 的短代码。
- 被追问实现细节时，能区分 Python 语言规则与 CPython 的缓存或驻留行为。
- 不确定细节时能明确说明边界，而不是把“通常如此”说成绝对规则。
