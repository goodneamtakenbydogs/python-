# 第 15 章学习单：Python 自动化脚本设计

## 1. 本章为什么要学

把几项操作写进一个脚本，不代表失败时仍能正确判断、停止和清理。本章从本地快照检查开始，将执行、解析、业务判断、预算、轮询与报告组合为可测试的流程。

学习目标围绕 Python 程序设计，不要求真实系统、账号或项目经历。完整网络、操作系统、服务器与设备课程另行学习；这里使用虚构文件、本地子进程和可控替身。

## 2. 前置知识与环境

- 第 1～3 章：类型、假值、对象共享、函数接口与作用域。
- 第 5～9 章：迭代、对象、异常、资源清理、导入与复制。
- 第 10 章：线程池、Future、等待和取消的边界。
- 第 11～12 章：测试、诊断、JSON、路径、subprocess、argparse 与临时文件。
- 第 13 章：独立预期、状态、失败场景、风险与证据。
- 第 14 章：pytest、替身、隔离与生命周期。

验证基线为 CPython 3.12.13、pytest 9.1.1。示例脚本只依赖标准库，测试使用现有开发环境，不新增运行库。Notebook 需选择仓库对应内核；真实进程只运行本地 Python，均有等待上限。

## 3. 学习目标

能为小脚本写出输入、输出、前置、异常、退出状态和副作用约定。能把外部操作与纯判断分开，用执行器封装调用，独立解释命令、协议与业务结果。

能为轮询和重试设计单次上限、总体预算、次数、状态终止和清理，用可控时钟与替身验证边界。能说明超时后的未知结果、重复执行与部分成功风险，组织一组有编号的小批量结果。

## 4. 知识点清单

### 4.1 输入与执行

- 从手工步骤提取脚本接口和副作用。
- 纯判断、外部操作、依赖注入与入口分离。
- 命令行、配置文件、环境和默认覆盖。
- 缺失、零、False、None 与有限数值校验。
- 路径基准、编码、程序与实参列表。
- 工作目录、环境副本、stdout、stderr 和 returncode。
- 执行、解析、状态和业务判断的分类。

### 4.2 时间、失败与资源

- JSON 协议结构、精确类型与独立预期。
- 单次超时、单调时钟、deadline 和剩余预算。
- 返回后校验、截止点、迟到结果与协作限时。
- pending、ready、failed、未知状态与有限轮询。
- 尝试次数、等待截断、退避、抖动和重试条件。
- 幂等性、结果未知、部分成功和补偿。
- 取得与清理责任、提前退出、管道和进程边界。
- 报告提交、旧目标保护及保存失败。

### 4.3 证据与组合

- 结构化结果、日志、退出状态与关联编号。
- 可控执行器、时钟、等待和故障注入。
- 小批量编号、部分结果、有限并发与 Future 映射。
- 取消待运行工作、正在执行工作与池退出。
- 远程适配边界与单文件拆分时机。

## 7. 实验与综合任务

24 道观察题保留 prediction 和 observation 两份记录。先读源码不运行，填写预测；运行后填写实际值并做当前题即时检查。替换整个占位字符串，包括引号；保留两位编号。错误预测不抹去，原因区说明修正依据。

四项实现分别是配置覆盖、分层结果分类、有限状态等待和执行器封装。每项明确输入、输出、错误与交互要求，检查不依赖其他题已完成。不要为验证时间逻辑写真实无限等待；用本题的时钟和等待替身。

综合任务在个人副本或临时目录完成：写小流程接口，运行正常与数量不符，注入依赖失败、时间边界和报告失败，记录首次证据并说明未知状态。人工评审不包含在 run_checks 的通过结论中。

### 8.1 知道

- [ ] 能解释执行器、解析器、业务判断、轮询与重试。

- [ ] 知道函数结果、异常与进程退出码分别给谁使用。

### 8.2 理解

- [ ] 能解释退出 0 为什么不代表结构合法或业务正确。
- [ ] 能解释零值与缺失、布尔与精确整数的不同。
- [ ] 能跟踪剩余预算、等待截断和截止点结果。
- [ ] 能说明超时、未知结果、幂等性与部分成功的关系。
- [ ] 能区分资源清理、业务补偿和报告提交。
- [ ] 能解释等待 Future 超时与停止正在运行工作为何不同。

### 8.3 会用

- [ ] 已完成 24 道观察题与逐题检查。
- [ ] 已完成四项实现，能检查结果和必要交互。
- [ ] 能用临时文件、本地子进程和可控时钟验证小流程。
- [ ] 能记录失败阶段、尝试编号与实际 timeout。
- [ ] 能完成综合方案，明确未测范围与清理责任。

### 8.4 能回答

- [ ] 能在 60～90 秒内说明一项脚本的约定与停止条件。
- [ ] 能解释一次失败后为什么可以或不可以重试。
- [ ] 能比较脚本正常通过、结果未知与报告失败。
