# 第 4 章复习卡：闭包、装饰器与函数式工具

本卡用于学完后的快速回忆，不代替完整讲义。

## 1. 函数对象、闭包与装饰器的关系

```text
函数是对象
→ 内层函数引用外层名字
→ 闭包保留所需绑定
→ 装饰器接收原对象并返回替代对象
→ 包装函数在调用时增加行为
```

## 2. 核心术语

| 术语 | 快速回忆 |
|---|---|
| 一等对象 | 能被名字引用、存入容器、作为实参和返回值的对象；Python 函数对象具备这些能力 |
| 高阶函数 | 接收函数对象或返回函数对象的函数 |
| 嵌套函数 | 定义在另一个函数体内的函数 |
| 自由变量 | 内层函数使用、但不在自身局部绑定的外层名字 |
| 闭包 | 函数及其继续访问所需外层绑定形成的组合 |
| 晚绑定 | 自由变量通常在函数调用时读取当前绑定 |
| 装饰器 | 接收被装饰对象并返回替代对象的可调用对象 |
| 包装函数 | 代替原函数接收调用并附加行为的函数 |
| 装饰器工厂 | 接收配置并返回真正装饰器的函数 |
| 函数工厂 | 创建并返回带有独立配置或外层绑定的函数 |
| 回调 | 交给其他代码、由接收方在适当时机调用的函数 |
| 元数据 | 函数名称、文档字符串、类型注解等描述信息 |
| 序列化 | 把对象或状态转换成适合保存、传输和恢复的形式 |
| 缓存命中/未命中 | 已有可复用结果 / 需要真正执行并保存结果 |
| 缓存过期/失效 | 到期不再使用 / 数据变化时主动删除记录 |
| 纯函数 | 结果只由输入决定，并且不修改外部可观察状态的函数 |
| I/O | 程序与文件、网络、终端等外部环境进行输入输出 |
| 日志 | 按时间和级别记录程序运行事件的信息 |
| 鉴权 | 确认调用者身份并检查其操作权限 |
| 重试 | 操作失败后再次执行同一操作以尝试恢复 |
| 幂等 | 同一操作重复执行，最终业务效果与执行一次一致 |

```text
double      → 名字当前指向函数对象
double(6)   → 调用表达式，结果是 12
apply       → 接收函数对象，因此是高阶函数
传入的 double → 由 apply 调用，因此在该场景中扮演回调
```

## 3. 闭包判断

```python
def make_multiplier(factor):
    def multiply(value):
        return value * factor

    return multiply
```

`multiply` 的局部没有绑定 `factor`，却使用外层函数中的 `factor`，因此 `factor` 是自由变量。返回的函数仍需要这个绑定，形成闭包。

闭包不是把函数体复制一份，也不是简单保存打印出来的旧值；它保留的是继续解析自由变量所需的绑定。

## 4. `nonlocal`

- 只读取外层名字不需要 `nonlocal`。
- 要让内层赋值修改已有外层绑定，需要 `nonlocal`。
- 修改外层列表内容不等于重新绑定列表名字，因此通常不需要 `nonlocal`。

## 5. 晚绑定

危险模型：

```text
循环创建多个函数
→ 每个函数引用同一个循环变量
→ 循环结束后变量停在最终值
→ 之后调用时都读取最终绑定
```

两种常见修复：

```python
functions.append(lambda value=number: value)
```

或者使用函数工厂，让每次调用建立独立外层作用域。

## 6. 装饰器展开

```python
@trace
def calculate(value):
    return value * 2
```

等价核心：

```python
def calculate(value):
    return value * 2


calculate = trace(calculate)
```

装饰发生在定义阶段；包装函数通常在以后调用 `calculate(value)` 时才执行。

## 7. 正确包装器清单

```python
from functools import wraps


def trace(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print("before")
        result = function(*args, **kwargs)
        print("after")
        return result

    return wrapper
```

检查：

- 是否接收原函数。
- 是否返回包装函数。
- 是否正确转发 `*args`、`**kwargs`。
- 是否返回原函数结果。
- 是否需要在异常时仍执行后置行为。
- 是否使用 `wraps` 保留元数据。

## 8. `wraps`

- 没有 `wraps` 时，装饰后的 `__name__` 和文档通常来自 `wrapper`。
- `@wraps(function)` 复制常用元数据并设置 `__wrapped__`。
- `wraps` 不会自动修复实参转发、返回值、异常或业务逻辑。

## 9. 带配置的装饰器

```python
@repeat(3)
def greet():
    return "hello"
```

三层：

```text
repeat(3)              → 返回 decorator
decorator(greet)       → 返回 wrapper
wrapper()              → 调用原 greet 三次
```

## 10. 多个装饰器

```python
@outer
@inner
def work():
    pass
```

定义阶段：

```python
work = outer(inner(work))
```

调用阶段通常：

```text
进入 outer
→ 进入 inner
→ 原函数
→ 离开 inner
→ 离开 outer
```

## 11. 类装饰器的基本用法

类定义完成后也会得到类对象。类装饰器接收这个类对象，并返回原类或替代对象。注册类、补充标记是常见场景；类和实例的完整机制在第 6 章学习。

## 12. `lambda`

- `lambda parameters: expression` 创建函数对象。
- 只能写一个表达式，其结果自动成为返回值。
- 适合简短 `key` 或局部回调。
- 多步骤、异常处理或复杂分支使用普通 `def`。
- `lambda` 与普通函数一样遵守 LEGB 和晚绑定。

## 13. `map()`、`filter()` 与推导式

- `map(function, values)`：对元素应用函数。
- `filter(predicate, values)`：保留判定为真的元素。
- Python 3 中二者按需产生结果，直接观察全部内容时常转换为 `list`。
- 简单转换和筛选通常用推导式更直观；已有命名函数时 `map()` 也可能清楚。
- 完整迭代器和惰性计算在第 5 章学习。

## 14. `reduce()` 与 `partial()`

- `reduce(function, iterable, initial)` 把序列逐步合并为累计结果。
- 空输入是否可处理与有没有 `initial` 有关。
- `partial(function, fixed_value)` 返回预先固定部分实参的新可调用对象。
- `partial` 不会执行原函数，直到返回对象被调用。
- `partial` 返回可调用对象，不保证是由 `def` 创建的普通函数对象。

## 15. `lru_cache()`

```python
from functools import lru_cache


@lru_cache(maxsize=128)
def calculate(value):
    return value * value
```

- 相同缓存键可以直接复用结果。
- 参与缓存键的实参必须可哈希。
- `typed=True` 要求不同直接实参类型形成不同缓存项；它不会递归区分容器内部类型。
- `cache_info()` 查看命中和未命中。
- `cache_clear()` 清空缓存。
- `lru_cache` 不提供按时间自动过期；LRU 描述的是容量满时的淘汰顺序。
- 缓存会持有实参和结果，可能增加内存占用。
- 外部状态、时间、随机数和副作用函数通常不适合直接缓存。
- 返回可变对象时，调用者可能共享同一缓存结果。

## 16. 常见陷阱

1. 混淆指向函数对象的名字、函数对象和调用结果。
2. 把嵌套函数都叫闭包，忽略自由变量。
3. 认为闭包复制了定义时的普通值，无法解释晚绑定。
4. 重新绑定外层名字时忘记 `nonlocal`。
5. 装饰器没有返回包装函数。
6. 包装器忘记返回原函数结果。
7. 包装器形参写死，导致原函数其他调用方式失效。
8. 不使用 `wraps`，破坏函数名称、文档和检查工具。
9. 混淆装饰阶段和调用阶段。
10. 判断多个装饰器顺序时只背“从下到上”，不区分定义与调用。
11. 用复杂 `lambda` 牺牲可读性。
12. 忘记 `map()`、`filter()` 在 Python 3 中不是列表。
13. 对包含不可哈希实参的调用使用 `lru_cache`。
14. 缓存依赖外部状态或具有副作用的函数。
15. 重试装饰器吞掉最终异常或重复不可安全重试的操作。

## 17. 面试回答骨架

闭包：

```text
内层函数
→ 使用外层自由变量
→ 外层调用结束后仍需该绑定
→ 形成闭包
→ 说明 nonlocal 或晚绑定边界
```

装饰器：

```text
函数也是对象
→ decorator 接收原函数
→ 返回 wrapper 替代原名字
→ wrapper 调用原函数并附加行为
→ wraps 保留元数据
```

缓存：

```text
调用实参形成键
→ 命中复用结果，未命中执行函数
→ 参与缓存键的实参需可哈希
→ 检查副作用、过期和内存
```
