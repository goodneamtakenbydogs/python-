### 第 39 题：屏障控制的线程输出

在常规 CPython 3.12 中预测输出，说明 Barrier 对执行顺序施加了什么约束：

```python
from threading import Barrier, Thread

state = {'count': 0}
barrier = Barrier(2, timeout=5)

def work():
    old = state['count']
    barrier.wait()
    state['count'] = old + 1

threads = [Thread(target=work) for _ in range(2)]
for thread in threads:
    thread.start()
for thread in threads:
    thread.join()
print(state['count'])
```

### 第 40 题：gather 失败后的任务状态

在 Python 3.12 脚本中预测三行输出，区别 gather 的失败与循环退出清理：

```python
import asyncio

async def main():
    started, release = asyncio.Event(), asyncio.Event()
    async def work():
        started.set()
        await release.wait()
        return 'done'
    async def fail():
        await started.wait()
        raise ValueError('failed')
    task = asyncio.create_task(work())
    try:
        await asyncio.gather(task, fail())
    except ValueError:
        print('caught')
    print(task.done())
    release.set()
    print(await task)

if __name__ == '__main__':
    asyncio.run(main())
```
