```python
def discounted(total):
    if total > 100:
        return total - 10
    return total

print(discounted(80))
print(discounted(120))
print(discounted(100))
```

### 第 41 题：拒绝事件后的代码状态

本模型 queued 只允许 start 或 cancel。预测输出并说明断言范围：

```python
state = 'queued'
before = state
allowed = {'start': 'running', 'cancel': 'cancelled'}
try:
    event = 'finish'
    if event not in allowed:
        raise ValueError('invalid event')
    state = allowed[event]
except ValueError:
    print('rejected')
print(state)
print(state == before)
```
