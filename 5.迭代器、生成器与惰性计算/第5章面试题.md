### 第 22 题：生成器何时执行

写出事件列表的每一步变化：

```python
events = []

def produce():
    events.append("start")
    yield 1
    events.append("middle")
    yield 2
    events.append("end")


generator = produce()
print(events)
print(next(generator), events)
print(next(generator), events)
```

最后一次 `yield 2` 后，`"end"` 是否已经加入？为什么？

### 第 23 题：生成器的 `return` 值

```python
generator = sample()
print(next(generator))

try:
    next(generator)
except StopIteration as error:
    print(error.value)
```

### 第 27 题：`yield from` 与 `yield`

分别写出两个函数的结果：

```python
groups = [[1, 2], [3]]

def first():
    for group in groups:
        yield group

def second():
    for group in groups:
        yield from group


print(list(first()))
print(list(second()))
```

### 第 28 题：`send()` 的暂停位置


### 第 33 题：修复重复消费错误
