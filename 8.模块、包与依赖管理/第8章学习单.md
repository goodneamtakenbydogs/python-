# 第 8 章学习单：模块、包与依赖管理

## 1. 为什么学这一章

代码从一个 Notebook 拆成多个文件后，问题不再只是“函数写对了吗”。Python 需要知道从哪里找模块、模块是否已经加载、相对导入以哪个包为起点；项目还要回答使用哪个解释器、安装哪些第三方发行包、版本由谁约束，以及另一台机器怎样得到一致环境。

本章主线是：

```text
源码文件与目录
→ 模块对象和包
→ 导入查找、执行与缓存
→ 项目安装和运行入口
→ 虚拟环境与第三方依赖
→ 声明、解析、锁定和复现
```

## 2. 前置知识

- 第 1 章：名字、对象、赋值和命名空间。
- 第 3 章：函数作用域与模块全局名字。
- 第 6 章：类也是对象，属性通过点号访问。
- 第 7 章：导入失败时的异常链与排查方法。

本章会读少量 TOML、命令行和目录树。它们第一次出现时会说明用途，不默认你已经会构建或发布 Python 包。

## 3. 知识点与目标

### 3.1 模块与导入

- 区分源文件、模块对象、导入名和当前命名空间中的名字。
- 逐步解释模块解析、查找、创建、提前放入 `sys.modules`、执行和绑定。
- 比较 `import module`、`from module import name` 与 `as` 的绑定结果。
- 理解 `__name__`、`__package__`、`__spec__` 和 `python -m` 的角色。
- 分析 `sys.path`、当前运行入口、安装位置和 `PYTHONPATH` 对查找的影响。
- 识别模块遮蔽、重复导入、重新加载和循环导入问题。

### 3.2 包与项目结构

- 区分普通包、`__init__.py`、子模块与命名空间包。
- 比较绝对导入和相对导入，说明直接运行包内文件为何可能失败。
- 理解 `__all__` 与星号导入的边界，它不等于安全访问控制。
- 设计可安装的项目结构，理解 `src` 布局解决的路径错觉。
- 区分导入包、发行包、项目目录和仓库。

### 3.3 环境与依赖

- 用 `sys.executable`、`sys.prefix`、`sys.base_prefix` 判断正在使用的解释器与虚拟环境。
- 解释虚拟环境隔离了什么、没有隔离什么。
- 理解 `python -m pip`、`pip` 与解释器对应关系。
- 说明 `pyproject.toml`、`requirements.txt`、锁文件的不同职责。
- 区分直接依赖、传递依赖、运行依赖、开发依赖和可选依赖。
- 阅读兼容版本约束，理解解析冲突和锁定结果。
- 解释可编辑安装及其适用边界。
- 使用当前项目中的 `uv` 文件理解同步和复现，不要求依赖某个工具才能回答通用原理。

## 4. 推荐顺序与时间

建议 24～30 小时：

| 内容 | 时间 |
|---|---:|
| 模块对象、导入绑定与执行缓存 | 5～6 小时 |
| `__main__`、搜索路径和错误模块遮蔽 | 4～5 小时 |
| 包、相对导入、循环导入和重新加载 | 5～6 小时 |
| 项目结构、虚拟环境和安装模型 | 4～5 小时 |
| 依赖声明、解析、锁定与 Notebook 复盘 | 6～8 小时 |

第一轮读讲义第 1～13 节并完成导入实验；第二轮学习包结构和循环导入；第三轮结合当前 `python八股` 项目理解虚拟环境、`pyproject.toml` 与 `uv.lock`。命令不要只背文本，要始终确认“它由哪个解释器执行、改变哪个环境”。
