# 第 8 章面试题：模块、包与依赖管理

先闭卷回答，再查看 `第8章参考回答.md`。导入问题应说明当前解释器、导入名、搜索位置、缓存状态和实际来源；依赖问题应区分声明范围与锁定版本。

## 一、基础概念题

### 第 1 题：源文件、导入名与模块对象

源文件、导入名和模块对象分别是什么？为什么模块不一定对应普通 `.py` 文件？

### 第 2 题：首次导入过程

从 `import shop.pricing` 开始，依次说明缓存检查、模块查找、创建、执行与当前名字绑定。为什么模块对象会在执行完成前进入 `sys.modules`？

### 第 3 题：导入执行模块顶层

导入模块时哪些代码会执行？函数定义与函数体的时机有何区别？为什么应限制导入时的网络或数据库副作用？

### 第 4 题：三种导入绑定

比较 `import module`、`from module import name`、`import module as alias`。模块属性随后重新绑定或内部可变对象被修改时，各导入者可能看到什么？

### 第 5 题：`sys.modules`

它保存什么？重复导入为什么通常不会重新执行模块？这个缓存跨进程共享吗？随意删除其中的键会有什么风险？

### 第 6 题：重新加载

`importlib.reload()` 大致做什么？为什么已有实例、`from ... import ...` 得到的名字和旧类引用不会全部自动更新？

### 第 7 题：`__name__` 与入口保护

模块被导入和作为入口执行时，`__name__` 分别是什么？`if __name__ == "__main__":` 阻止了哪些行为，又没有阻止什么？

### 第 8 题：按路径执行与 `-m`

为什么直接运行 `python shop/cli.py` 可能让相对导入失败，而 `python -m shop.cli` 可以工作？`__package__` 在这里解决什么问题？

### 第 9 题：模块规格

`__spec__` 和 `importlib.util.find_spec()` 能帮助回答什么？为什么不能假定 `spec.origin` 永远是普通文件路径？

### 第 10 题：`sys.path`

它是什么、从哪些来源形成？为什么 IDE、终端、Notebook 和测试工具可能得到不同搜索路径？临时修改它为什么不适合长期修复项目结构？

### 第 11 题：模块遮蔽

本地 `json.py` 或 `requests.py` 会造成什么问题？怎样用 `__file__` 和 `__spec__.origin` 确认实际导入来源？

### 第 12 题：普通包与 `__init__.py`

普通包和模块有什么关系？导入 `shop.pricing` 时 `shop/__init__.py` 何时执行？为什么不应在包初始化中导入所有内部模块？

### 第 13 题：绝对与相对导入

两者以什么为起点？一个点、两个点分别表示什么？相对导入为何不是相对于当前工作目录？

### 第 14 题：`__all__`

它主要影响什么？没有 `__all__` 时星号导入通常怎样处理下划线名字？它能否阻止显式访问内部对象？

### 第 15 题：命名空间包

为什么同一顶层包可以由多个目录贡献子包？它与忘写 `__init__.py` 的普通包有什么区别和限制？

### 第 16 题：循环导入

为什么循环导入有时成功、有时出现“partially initialized module”？把模块提前放入 `sys.modules` 与这个现象有何关系？

### 第 17 题：处理循环导入

提取共同依赖、依赖反转、减少包重导出、局部导入分别怎样缓解问题？为什么局部导入不是万能重构？

### 第 18 题：常见导入错误

比较 `ModuleNotFoundError`、`ImportError: cannot import name`、部分初始化 `AttributeError` 和“导入成功但来源错误”。排查顺序是什么？

## 二、环境与代码理解题

### 第 19 题：模块引用与直接成员绑定

写出输出并解释：

```python
import types

module = types.ModuleType("settings")
module.mode = "dev"
module_reference = module
imported_mode = module.mode
module.mode = "prod"
print(module_reference.mode, imported_mode)
```

### 第 20 题：共享可变成员

写出输出，说明是否复制了列表：

```python
import types

module = types.ModuleType("registry")
module.items = []
items = module.items
module.items.append("A")
print(items, items is module.items)
```

### 第 21 题：模块缓存身份

写出结果：

```python
import math
import sys

again = __import__("math")
print(math is again)
print(sys.modules["math"] is math)
```

### 第 22 题：脚本运行与按模块名导入

若同一个源码文件先作为 `__main__` 运行，又在该进程中按正式导入名加载，为什么可能形成两个模块对象和两份全局状态？

### 第 23 题：包初始化顺序

`shop/__init__.py` 初始化 `EVENTS = ["package"]`，`shop/child.py` 导入 `EVENTS` 后追加 `"child"`。首次导入 `shop.child` 后事件顺序是什么？父包上为何通常出现 `child` 属性？

### 第 24 题：循环初始化时间线

`a.py` 先导入 `b.py`，`b.py` 又导入 `a.py` 并立刻读取 `a.READY`，而 `a.py` 在导入 `b` 之后才设置 `READY = True`。逐步说明失败发生在哪一行。

### 第 25 题：虚拟环境诊断

`sys.executable`、`sys.prefix`、`sys.base_prefix` 分别提供什么证据？`sys.prefix != sys.base_prefix` 能证明依赖版本已经固定吗？

### 第 26 题：终端与 Notebook 环境不同

终端里安装后可以导入，Notebook 仍报找不到模块。最可能的原因是什么？应在两边检查哪些值？

### 第 27 题：导入包与发行包

为什么 `import yaml` 对应的安装发行包可能叫 `PyYAML`？看到导入失败后直接安装同名项目有哪些风险？

### 第 28 题：项目结构

`src/my_app` 布局相对把 `my_app` 直接放仓库根目录，主要减少了什么路径错觉？它是否适合所有一次性脚本？

### 第 29 题：`pyproject.toml`

它可以声明哪些内容？`dependencies = []` 和开发依赖组中存在 pytest 分别说明什么？它是否等于当前环境已经同步？

### 第 30 题：`python -m pip`

为什么它比裸 `pip` 更容易确认目标解释器？如果 `python` 本身指错环境，是否仍然安全？
