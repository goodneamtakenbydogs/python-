# 第 6 章学习单：面向对象与 Python 数据模型

## 1. 本章为什么要学

前五章已经把列表、函数和迭代器当作对象使用。本章要回答：怎样定义自己的对象，名字和属性怎样找到它保存的数据，以及为什么 `print(obj)`、`obj == other`、`len(obj)` 等语法能用于自定义对象。

本章的主线是：

```text
类定义可创建的对象及其行为
→ 实例保存各自的状态
→ 属性查找和方法调用决定用到谁的状态
→ 继承与组合复用行为
→ 特殊方法让对象参与 Python 的内置操作
```

## 2. 前置知识

- 第 1 章：名字绑定、对象身份、可变性，以及 `==` 与 `is`。
- 第 2 章：字典、集合、哈希和容器协议的使用现象。
- 第 3 章：形参绑定、`self` 所需的函数调用模型与作用域。
- 第 4 章：装饰器、`@property` 所需的最低直觉。
- 第 5 章：`iter()`、`next()` 和迭代器协议。

遇到异常和 `with` 时，本章会解释当前代码所需的最低含义；完整异常与资源管理放在第 7 章。

## 3. 学习目标与知识点

### 3.1 类、实例与属性

- 解释执行 `class`、创建实例、运行 `__new__()` 和 `__init__()` 的先后关系。
- 区分实例属性、类属性和属性遮蔽；能画出共享可变类属性的对象关系。
- 分析普通属性、实例字典、类和父类中的查找，以及描述符造成的优先级例外。
- 区分实例方法、类方法和静态方法的绑定方式与用途。
- 能从具体调用表达式判断自动绑定的是实例、类，还是不自动绑定任何对象。

### 3.2 继承、组合与类的约束

- 理解继承、方法重写、多态、鸭子类型与组合的差别。
- 读懂多继承的 MRO，并解释零参数 `super()` 为什么不总是“直接父类”。
- 理解单下划线约定、双下划线名称改写、`property`、`__slots__` 的用途与边界。
- 知道抽象基类、`dataclass` 分别解决什么问题。

### 3.3 Python 数据模型

- 区分 `__str__()` 与 `__repr__()`。
- 解释 `__eq__()`、`NotImplemented` 与 `__hash__()` 的关系，避免制造会变化的字典键。
- 了解 `__lt__()` 等排序比较方法。
- 使用 `__len__()`、`__getitem__()`、`__contains__()` 和 `__call__()`。
- 区分 `__getattr__()`、`__getattribute__()`、`__setattr__()`；认识描述符与元类的最低限度含义。
- 认识 `__enter__()`、`__exit__()` 与下一章 `with` 的联系。
