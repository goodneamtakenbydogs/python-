### 第 6 题：`__new__()` 与 `__init__()`

### 第 7 题：继承与方法重写

继承表示什么关系？子类重写父类方法时，调用子类实例的方法会从哪里查找？这种设计可能带来什么维护成本？

### 第 8 题：多态与鸭子类型

多态和鸭子类型分别强调什么？一个对象没有继承指定基类，但提供调用方需要的方法时，是否仍可能工作？

### 第 9 题：组合与继承

“报告服务使用一个打印器”和“邮件是一种消息”分别更接近组合还是继承？选择依据是什么？

### 第 10 题：MRO

多继承中的 MRO 用来解决什么问题？怎样观察一个类的 MRO？对 `Combined(Left, Right)` 且 `Left(Root)`、`Right(Root)` 的结构，为什么不能把 `Root` 放在 `Right` 前面，也不能把它重复执行两次？

### 第 11 题：`super()`

### 第 12 题：名称改写

### 第 13 题：`property`

### 第 22 题：实例、类和静态方法

写出结果，并解释 `cls` 绑定到哪个类：

```python
class Ticket:
    prefix = "T"

    def __init__(self, number):
        self.number = number

    def label(self):
        return f"{self.prefix}-{self.number}"

    @classmethod
    def build(cls, number):
        return cls(number)

    @staticmethod
    def valid(number):
        return number >= 0


class SpecialTicket(Ticket):
    prefix = "S"


item = SpecialTicket.build(4)
print(type(item).__name__, item.label(), Ticket.valid(-1))
```

### 第 25 题：菱形继承

先写出 MRO，再写出 `Combined().route()`：

```python
class Root:
    def route(self):
        return ["Root"]


class Left(Root):
    def route(self):
        return ["Left"] + super().route()


class Right(Root):
    def route(self):
        return ["Right"] + super().route()


class Combined(Left, Right):
    def route(self):
        return ["Combined"] + super().route()

```

### 第 26 题：`property` 校验

说明创建和赋值的先后状态，以及失败后保存的值：

```python
class Account:
    def __init__(self, balance):
        self.balance = balance

    @property
    def balance(self):
        return self._balance

    @balance.setter
    def balance(self, value):
        if value < 0:
            raise ValueError("negative")
        self._balance = value


account = Account(10)
try:
    account.balance = -1
except ValueError:
    pass
account.__dict__["balance"] = 999
print(account.balance, vars(account))
```

### 第 30 题：打印与调用

写出输出，并指出哪个特殊方法处理 `operation(4)`：

```python
class Multiplier:
    def __init__(self, factor):
        self.factor = factor

    def __str__(self):
        return f"x{self.factor}"

    def __repr__(self):
        return f"Multiplier(factor={self.factor!r})"

    def __call__(self, value):
        return self.factor * value


operation = Multiplier(3)
print(str(operation), repr(operation), operation(4))
```
