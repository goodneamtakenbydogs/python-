# 第 11 章学习单：类型标注、测试与调试

## 1. 本章为什么要学

会解释 Python 的运行规则之后，还要能说明函数期望什么、怎样验证实际行为、失败时怎样定位。本章建立这三项基础，使后续测试开发专项有可运行、可解释的代码基础。

学习时分开回答：类型关系是否合理、实际输入是否有效、测试预期是否有依据、错误证据是否充分。不要把任何一项工具通过当作全部正确性的证明。

## 2. 前置知识

- 第 1～3 章：对象、类型、真假值、函数签名、异常接口与局部绑定。
- 第 4～5 章：装饰器、可调用对象、可迭代对象和生成器。
- 第 6 章：类、实例、方法、继承与行为协议。
- 第 7 章：异常传播、原因链、上下文管理和清理责任。
- 第 8 章：模块导入、名字绑定、虚拟环境与命令行入口。
- 第 9～10 章：共享状态、对象生命周期、可重复观察与并发隔离。

不要求提前学过静态类型语言或测试框架。讲义会解释类型收窄、泛型、结构化类型、fixture、替身、日志器与性能报告字段。

## 3. 学习目标

能为小接口写出合适标注，并解释标注与运行时校验的区别；能从明确约定选择正常、边界和异常输入，使用 unittest 与 pytest 运行小测试；能控制依赖、时间或环境而不污染后续用例。

能从 traceback、日志和断点检查首次错误状态；能用 timeit 测量小操作、用 cProfile 找调用热点，说明测量范围与局限。测试预期、真实集成和系统性能仍需各自证据。

## 4. 知识点清单

### 4.1 类型标注与静态检查

- 变量、形参、返回值标注与运行时行为。
- 注解保存、前向引用、get_type_hints 与版本差异。
- 容器、联合类型、Optional、Literal、Any、object 与 cast。
- Callable、Iterable、Iterator 与 Generator 的关系。
- 类型别名、TypeVar、泛型与可变容器不变性。
- Protocol、结构化子类型、抽象基类与运行时检查边界。
- mypy、Pyright 的输入、配置和证据范围。

### 4.2 基础测试与依赖控制

- 测试层次、接口约定与独立预期。
- 准备、执行与断言，正常、边界、异常和副作用。
- assert 的优化边界与显式输入校验。
- unittest 的用例、套件、运行器、失败与错误。
- setUp、tearDown、addCleanup 与部分初始化失败。
- pytest 的发现、执行、退出结果与异常断言。
- 参数化、fixture 默认作用域、yield 清理与共享对象。
- tmp_path、monkeypatch、本地随机发生器与可重复性。
- Mock、side_effect、调用记录、patch 查找位置与 autospec。
- 异步替身的调用、等待和结果责任。

### 4.3 调试、日志与代码性能

- 临时打印、日志和断点的适用场景。
- logger、handler、formatter、过滤与传播。
- 异常日志、重复上报、敏感信息和全局配置边界。
- traceback 的调用路径、失败行与原因链。
- pdb、IDE 断点、单步、调用现场和观察副作用。
- 最小复现、修复假设与回归证据。
- timeit 的组数、次数、准备、输入状态与 GC。
- cProfile 的调用数、自身时间、累计时间与热点。
- 格式化、lint、类型检查与测试的分工。

## 7. 环境与实验方式

沿用项目 CPython 3.12.13 环境，pytest 已列入开发依赖。在仓库目录使用 `uv sync --group dev` 准备环境，再用对应内核打开 Notebook。mypy 与 Pyright 的命令行练习可按讲义使用隔离工具环境，不是 Notebook 运行前置。

实验 1～26 把 prediction 与 observation 分开。把整个占位字符串替换为值，预测错误时保留原记录，原因解释区说明差异。每题紧跟 `check_experiment(globals(), 编号)`，完成全部题目后再 `run_checks(globals())`。

实验 27～30 分别实现端口解析、注入读取依赖的标签收集、区间函数用例数据和检查候选实现的测试函数。测试编写题会检查预期依据、代表性场景，以及对典型错误的识别；检查通过不能证明已经覆盖所有需求。

pytest 观察题运行题面可见源码的临时子进程，故意失败的测试也会变成报告计数，不应修改为全部通过来填写结果。日志实验不重配 root，pdb 使用固定输入的独立脚本，不会等待你退出内核交互提示。计时不要求具体秒数。
