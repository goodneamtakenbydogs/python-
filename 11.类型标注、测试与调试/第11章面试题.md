```python
print(twice(claimed))
print(type(claimed).__name__)
```

### 第 41 题：导入绑定与 patch 的代码结果

预测三个输出，说明实际查找位置：

```python
from time import monotonic
from unittest.mock import patch
import time

original = monotonic
with patch('time.monotonic', return_value=1):
    print(time.monotonic())
    print(monotonic is original)
with patch(__name__ + '.monotonic', return_value=2):
    print(monotonic())
```

### 第 42 题：修复共享 fixture 数据

```python
shared = []

@pytest.fixture
def records():

    records.append('A')
    assert records == ['A']

    assert records == []
```
