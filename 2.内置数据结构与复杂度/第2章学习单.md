# 第 2 章学习单：内置数据结构与复杂度

## 1. 本章为什么要学

写 Python 时，很多代码都能用不止一种容器完成。数据量很小时，不同写法看起来都能运行；数据量变大后，容器选择和操作位置会直接决定程序是迅速完成，还是明显变慢。

例如，`value in values` 写法相同，但 `values` 是列表还是集合，查找过程并不相同。再例如，`list.pop()` 和 `list.pop(0)` 只差一个位置实参，时间复杂度却不同。

本章的目标不是背完所有方法，而是形成下面的判断链：

```text
我要完成什么操作
→ 哪种容器支持这个操作
→ 这个操作为什么具有相应复杂度
→ 当前数据规模能否接受
→ 是否还有顺序、重复、可变性等约束
```

## 2. 学习目标

完成本章后，应当能够：

- 用自己的话解释时间复杂度和空间复杂度。
- 区分最坏、平均和摊销复杂度。
- 解释列表按下标访问快、从头部插入删除慢的原因。
- 根据顺序、重复、查找和更新需求选择 `list`、`tuple`、`dict` 或 `set`。
- 判断一个常见对象能否作为字典键或集合元素。
- 解释元组固定引用槽位与列表动态容量的区别，并区分语言保证与 CPython 实现。
- 解释字典和集合查找为什么通常是平均 `O(1)`，而不是绝对 `O(1)`。
- 正确使用 `deque`、`Counter`、`defaultdict` 和 `namedtuple` 的常见功能。
- 解释 `heapq` 为什么是最小堆，以及小顶堆如何服务 Top K。
- 识别遍历期间修改容器和嵌套浅拷贝的风险。
- 分析常见容器代码的主要时间与空间复杂度。

## 3. 前置知识

开始本章前，应理解第 1 章中的：

- 名字、对象、引用和赋值。
- 可变对象与不可变对象。
- `==` 与 `is`。
- 索引、切片、循环和成员运算 `in`。
- 列表、元组、字典和集合的基本字面量。

本章会使用简单函数和类来观察行为，但不会要求预先掌握第 3 章完整的实参与形参绑定模型或第 6 章的完整面向对象机制。

## 4. 本章知识点清单

### 4.1 复杂度的概念与分析方法

- 数据结构、API 和算法的最低限度含义。
- 输入规模 `n` 表示什么。
- 时间复杂度和空间复杂度。
- `O(1)`、`O(log n)`、`O(n)`、`O(n log n)` 和 `O(n²)` 的增长差异。
- 最坏复杂度、平均复杂度和摊销复杂度。
- 单次操作复杂度与整段算法复杂度。
- 为什么不能只根据代码行数判断复杂度。

### 4.2 `list`

- 列表作为动态顺序表的基本直觉。
- 按下标访问与从中间移动元素。
- 动态扩容和 `append()` 的摊销 `O(1)`。
- 索引、切片、成员查找和复制。
- `append()`、`extend()` 与 `insert()`。
- `remove()`、`pop()`、`del` 与 `clear()`。
- `reverse()`、`sort()`、`reversed()` 与 `sorted()`。
- 稳定排序、`key` 与 `reverse`。
- `lambda` 在排序 `key` 中只作最低限度预览，完整内容留到第 4 章。
- 遍历列表时修改列表的风险。

### 4.3 `tuple`

- 元组的不可变性。
- 元组保存固定数量对象引用的结构模型。
- CPython 元组固定槽位与列表动态容量的区别。
- 下标赋值为什么失败，以及不可变不是内存被硬件锁死。
- 拼接和 `+=` 为什么不会修改旧元组。
- 单元素元组的逗号。
- 元组解包。
- 元组内部仍可能引用可变对象。
- 元组能否作为字典键取决于什么。
- 元组适合表达固定结构数据的场景。

### 4.4 `dict`

- 键值映射和哈希表直觉。
- 哈希值、哈希位置和哈希冲突。
- 可哈希对象的基本要求。
- 相等对象与哈希值的关系。
- 哈希查找最后使用的是相等性协议而不是身份判断，并最低限度认识 `__eq__()` 与 `__hash__()`。
- 平均 `O(1)` 与最坏情况的区别。
- 字典的插入顺序保证。
- 读取、写入、覆盖和删除键。
- `get()`、`setdefault()`、`update()`、`pop()` 和 `popitem()`。
- `keys()`、`values()`、`items()` 视图。
- 遍历字典时改变大小的风险。

### 4.5 `set` 与 `frozenset`

- 集合的去重和成员查找。
- 集合没有按位置索引。
- 交集、并集、差集和对称差集。
- 子集、超集和不相交判断。
- `set` 与 `frozenset` 的可变性区别。
- 集合元素必须可哈希。
- 不能依赖集合遍历顺序。

### 4.6 专用容器

- `deque` 的双端追加和删除。
- `list` 与 `deque` 实现队列时的区别。
- `Counter` 的计数语义和常见操作。
- `defaultdict` 的默认工厂。
- `namedtuple` 的命名字段和不可变性。
- 标准库模块、默认工厂、属性错误和数据类等辅助术语的最低限度含义。

### 4.7 `heapq` 与 Top K

- 堆只保证局部顺序，不是完整排序。
- 树、根节点、父节点、孩子、二叉树和完整二叉树的最低限度含义。
- Python `heapq` 的最小堆规则。
- `heapify()`、`heappush()`、`heappop()` 和 `heapreplace()`。
- 为什么堆顶可以在 `O(1)` 读取。
- 为什么插入和弹出通常是 `O(log n)`。
- Python 3.11～3.13 使用负数模拟数值最大堆，以及 Python 3.14+ 公开最大堆接口的版本边界。
- 用大小为 `k` 的最小堆维护最大的 `k` 个元素。

### 4.8 容器共享、复制与选型

- 赋值共享同一个容器对象。
- 浅拷贝只复制外层容器。
- 嵌套可变对象仍可能共享。
- 顺序、重复、索引、查找、更新和两端操作对选型的影响。
- 可读性、复杂度和内存之间的取舍。

## 5. 推荐学习顺序

### 第一步：先学会读复杂度

先理解 `n`、增长速度和最坏/平均/摊销的区别，否则后面只能机械背诵复杂度表。

### 第二步：学习列表索引、末尾追加与头部插删

观察数组式存储的直觉，解释下标访问、末尾追加、头部插入和切片为什么代价不同。

### 第三步：学习 `tuple`

在已有列表经验上比较固定引用槽位与动态容量，解释为什么元组不能原地增删替换、为什么拼接会建立新结果，以及“能否哈希取决于内部元素”的约束。

### 第四步：进入 `dict` 和 `set`

先理解哈希、冲突和可哈希，再学习 API。不要把“平均 `O(1)`”背成任何情况下绝对不变的常数时间。

### 第五步：补充专用容器

用 `deque` 解决双端队列问题，用 `Counter` 和 `defaultdict` 减少手工状态维护，用 `namedtuple` 表达简单固定记录。

### 第六步：学习堆与 Top K

先理解堆顶代表什么，再学习 `heapq` 方法，最后处理“只保留最需要的 `k` 个候选”这一模型。

### 第七步：完成实验与面试练习

先预测再运行 Notebook，之后闭卷回答面试题，最后才对照参考回答和复习卡。

## 6. 建议学习时间

建议总时间为 12～15 小时，可以分为 5 次完成：

| 学习内容 | 建议时间 |
|---|---:|
| 复杂度与列表 | 3 小时 |
| 元组、字典与可哈希 | 3 小时 |
| 集合与专用容器 | 2.5 小时 |
| 堆、Top K 与容器选型 | 2.5 小时 |
| 代码实验、面试题和复盘 | 3～4 小时 |

第一次学习不要求一次背下全部复杂度。应先理解原因，再通过实验和题目反复调用。

## 8. 分层完成标准

### 8.1 知道

- 知道四种核心容器分别保存什么关系。
- 知道 `deque`、`Counter`、`defaultdict`、`namedtuple` 和 `heapq` 的主要用途。
- 知道常见复杂度符号描述增长速度。
- 知道字典键和集合元素需要可哈希。

### 8.2 理解

- 能解释列表按下标访问和头部删除复杂度不同的原因。
- 能解释元组不可变如何由固定结构与类型操作规则体现，而不只背诵结论。
- 能解释 `append()` 为什么是摊销 `O(1)`。
- 能解释字典查找为什么通常是平均 `O(1)`。
- 能解释哈希冲突不等于两个对象相等。
- 能解释字典为什么不能只比较哈希值，以及最后的相等确认来自哪里。
- 能解释堆为什么不等于完整有序列表。
- 能解释浅拷贝后嵌套对象为什么可能共享。

### 8.3 会用

- 能按需求正确选择列表、元组、字典或集合。
- 能使用 `deque` 实现真正的队列操作。
- 能使用 `Counter` 或 `defaultdict` 完成计数和分组。
- 能正确使用 `heapq` 维护有限候选。
- 能避免在遍历期间以危险方式改变容器大小。
- 能分析一段常见容器代码的总复杂度。

### 8.4 能回答

- 能在一分钟内对比 `list`、`tuple`、`dict` 和 `set`。
- 能准确使用“最坏”“平均”和“摊销”等限定词。
- 能解释可哈希的要求，而不只背“不可变对象才能当键”。
- 能结合具体操作说明为什么选择某种容器。
- 能处理面试官关于顺序、重复、复杂度和内存的继续追问。
