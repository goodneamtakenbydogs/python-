# 第 2 章面试题：内置数据结构与复杂度

这份文件用于闭卷口头练习，不提供答案。建议先用 30～90 秒说出结论，再解释容器内部需要完成的工作。回答复杂度时，必须说明它是平均、摊销还是最坏情况，并说清楚 `n`、`k` 等变量代表什么。

## 一、基础概念题

### 第 1 题：复杂度中的平均、摊销与最坏情况

时间复杂度描述什么？平均复杂度、摊销复杂度和最坏复杂度分别观察什么？为什么不能只说“`list.append()` 是 `O(1)`”而不说明语境？

### 第 3 题：列表常用操作及复杂度

比较以下列表操作的含义和时间复杂度：按下标读取、切片、`append()`、`extend()`、`insert()`、`pop()`、`remove()`、成员查找、`reverse()` 和排序。回答时定义 `n` 为原列表长度、`k` 为新增或切片元素数量。

### 第 4 题：`sort()` 与 `sorted()`

`list.sort()` 与 `sorted()` 有什么区别？它们的返回值、是否修改输入、适用对象及通常的时间复杂度分别是什么？为什么不应该写 `numbers = numbers.sort()`？

### 第 5 题：列表与元组

`list` 和 `tuple` 在可变性、存储结构、可用操作、复杂度和典型使用场景上有什么区别？请从常见 CPython 实现解释固定引用槽位与动态容量的差异，并说明 `tuple += other` 为什么不会修改旧元组。哪些结论属于 Python 语言保证，哪些只是 CPython 实现模型？“元组不可变”能否推出“元组一定可以作为字典键”？

### 第 6 题：可哈希对象

什么叫对象可哈希？作为字典键或集合元素的对象需要满足什么约束？为什么普通列表不能作为字典键，而只包含整数和字符串的元组通常可以？列表为什么不能在保留内容相等规则的同时改用对象身份哈希？

### 第 7 题：字典查找与哈希冲突

字典为什么能做到平均 `O(1)` 的插入、查找和删除？哈希值相同是否意味着两个键相等？哈希表缩小候选位置后，使用身份判断还是相等性协议确认键？`__hash__()` 与 `__eq__()` 在这里最低限度分别负责什么？为什么其最坏复杂度不能简单说成永远 `O(1)`？

### 第 8 题：字典顺序与视图

当前 Python 3 的普通字典对插入顺序有什么保证？更新已有键、删除后重新插入分别会怎样影响顺序？`keys()`、`values()`、`items()` 返回的是独立列表还是动态视图？

### 第 9 题：字典的读取与更新接口

比较下标读取、`get()`、`setdefault()`、`update()` 和字典推导式。哪些操作只读取，哪些可能修改字典？当默认值的构造成本较高时，使用 `get()` 或 `setdefault()` 还需要注意什么？

### 第 10 题：集合与不可变集合

`set` 适合解决哪些问题？解释去重、成员查找、交集、并集、差集和对称差集。`frozenset` 与 `set` 的核心区别是什么，它为什么可以在满足条件时作为字典键？

### 第 11 题：`list` 与 `deque`

若要实现队列，为什么通常选择 `collections.deque` 而不是反复调用 `list.pop(0)`？比较二者在两端操作、按下标访问和中间操作上的特点，不要把 `deque` 描述成所有场景都优于列表。

### 第 12 题：`Counter`、`defaultdict` 与 `namedtuple`

这三个 `collections` 工具分别解决什么问题？它们与普通 `dict`、手动初始化默认值、普通元组相比有什么收益和使用边界？

### 第 13 题：最小堆与 Top K

Python 的 `heapq` 经典接口默认维护什么堆？堆顶保证了什么，又没有保证什么？如果要从大量数据中保留最大的 `k` 个元素，为什么常维护一个大小不超过 `k` 的最小堆？请给出其时间和空间复杂度，并说明 Python 3.14 最大堆接口与较早版本取负方案的边界。
