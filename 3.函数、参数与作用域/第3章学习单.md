# 第 3 章学习单：函数、参数与作用域

## 1. 本章为什么要学

函数不是简单地把几行代码包起来。一次函数调用至少涉及四件事：

```text
先计算实参
→ 按函数签名绑定形参
→ 在新的局部作用域中执行函数体
→ 返回对象并结束本次调用
```

如果这四步没有建立清晰模型，就容易在可变形参、形参默认值、`global`、`nonlocal` 和递归中靠猜判断结果。

本章的核心问题是：**函数调用前后，哪些名字改变了绑定，哪些对象本身被修改了？**

## 2. 学习目标

完成本章后，应当能够：

- 解释函数对象、函数定义和函数调用的区别。
- 读懂函数签名并判断实参与形参怎样绑定。
- 区分位置实参、关键字实参与五类形参。
- 正确使用形参默认值、`*args` 和 `**kwargs`。
- 识别仅限位置形参与仅限关键字形参。
- 使用 `*` 和 `**` 展开调用参数。
- 解释默认值表达式为什么只在函数定义时计算一次。
- 修复可变默认值造成的跨调用共享。
- 准确解释 Python 的对象共享传参模型。
- 判断函数是在重新绑定局部名字，还是修改调用者也能看到的对象。
- 使用 LEGB 规则分析名字查找。
- 区分 `NameError` 与 `UnboundLocalError` 的典型原因。
- 区分 `global` 与 `nonlocal`。
- 理解函数注解不会默认强制检查运行时类型。
- 画出递归调用栈并确定终止条件与规模变化。
- 比较递归与迭代的时间、空间和适用场景。
- 把函数作为对象传递、保存和返回，为第 4 章做准备。

## 3. 前置知识

开始前应理解：

- 第 1 章的名字、对象、引用、赋值与可变性。
- 修改对象和重新绑定名字的区别。
- `None`、条件、循环和基本表达式。
- 第 2 章的列表、元组、字典及常见复杂度。

本章会短暂展示嵌套函数，但闭包、自由变量和装饰器会在第 4 章完整学习。

## 4. 本章知识点清单

### 4.1 函数基础

- 函数接口与程序状态的最低限度含义。
- 函数解决的重复、命名和职责划分问题。
- `def` 创建函数对象并绑定名字。
- 函数签名、函数体与调用表达式。
- 形参与实参。
- `return`、提前返回和默认返回 `None`。
- 返回多个值实际得到元组。
- 文档字符串、`__name__` 和 `__doc__`。
- 双下划线特殊属性的最低限度含义，以及它们与第 6 章特殊方法的联系。
- 函数对象与函数调用结果的区别。

### 4.2 参数种类与绑定

- 位置实参与关键字实参。
- 位置或关键字形参。
- 仅限位置形参 `/`。
- 仅限关键字形参 `*`。
- 可变位置形参 `*args`。
- 可变关键字形参 `**kwargs`。
- 形参默认值是附加配置，不是第六种形参类别。
- 参数声明顺序。
- 重复绑定、缺少参数和多余参数产生的 `TypeError`。

### 4.3 参数展开

- 调用时使用 `*sequence` 展开位置实参。
- 调用时使用 `**mapping` 展开关键字实参。
- 函数定义中的 `*`、`**` 与函数调用中的 `*`、`**`。
- 展开后发生重复绑定的风险。
- 普通位置实参必须位于普通关键字实参之前的基本规则。

### 4.4 形参默认值

- 默认表达式的计算时机。
- 可变默认对象被多次调用共享。
- 使用 `None` 延迟创建新对象。
- `None` 本身是合法业务值时使用专用哨兵对象。
- 在位置或关键字形参中，有默认值的形参应放在没有默认值的形参之后。

### 4.5 对象共享传参

- 形参是本次调用局部作用域中的名字。
- 实参对象与形参名字的绑定关系。
- 重新绑定形参不会改变调用者名字。
- 通过形参修改共享可变对象可能被调用者观察到。
- 不可变对象操作通常产生新对象并重新绑定。
- 返回新对象与原地修改输入的接口取舍。

### 4.6 作用域与 LEGB

- 局部作用域 Local。
- 外层函数作用域 Enclosing。
- 全局作用域 Global。
- 模块和“模块全局”的最低限度含义。
- 内置作用域 Built-in。
- 名字查找与名字赋值不是同一件事。
- 函数体中的赋值如何让名字成为局部名字。
- `UnboundLocalError`。
- `global` 声明。
- `nonlocal` 声明。
- 命名空间以及 `globals()`、`locals()` 的观察用途。
- `if`、`for` 等普通代码块不会创建函数式局部作用域。
- 遮蔽内置名字的风险。

### 4.7 函数对象与高阶函数

- 函数可以赋值给其他名字。
- 函数可以放进容器。
- 函数可以作为实参。
- 函数可以作为返回值。
- 回调函数和 `key` 函数。
- `callable()`。
- 函数属性的基本观察。
- 包装器、闭包、装饰器、`lambda` 和 `functools` 的最低限度预告。

### 4.8 函数注解

- 参数注解和返回值注解的写法。
- 注解主要表达接口意图。
- 静态检查器“不执行当前业务调用而分析代码”的最低限度含义。
- Python 默认不会根据注解自动阻止不匹配调用。
- `__annotations__`。
- 完整类型标注体系留到第 11 章。

### 4.9 递归与调用栈

- 递归、尾递归和尾递归优化的最低限度含义。
- 函数调用栈帧的基础直觉。
- 递归函数调用自身。
- 终止条件。
- 每次调用必须让问题规模接近终止条件。
- 返回值如何逐层返回。
- 递归深度限制。
- CPython 通常不进行尾递归优化。
- 递归与迭代的时间和额外空间比较。
- 树、回溯等递归适用场景只作最低限度解释。

## 5. 推荐学习顺序

### 第一步：学习函数调用的四个阶段

先区分函数对象、调用表达式、参数绑定和返回值，不急着背各种星号参数。

### 第二步：系统学习签名和参数绑定

从位置实参与关键字实参开始，再加入默认值、`/`、`*`、`*args` 和 `**kwargs`。每次都用具体调用验证谁绑定到谁。

### 第三步：解决形参默认值与对象共享

把第 1 章的对象模型带入函数调用，解释为什么有些修改能被调用者看到，以及为什么可变默认对象会跨调用共享。

### 第四步：建立 LEGB 模型

先学读取名字的顺序，再学习赋值对局部名字的影响，最后区分 `global` 和 `nonlocal`。

### 第五步：认识函数也是对象

练习保存和传递函数，为下一章闭包与装饰器建立前置直觉。

### 第六步：画递归调用栈

不要只看最终结果。写出每层参数、等待的返回值和结束位置，再比较迭代版本。

### 第七步：实验、口述与复盘

Notebook 先预测后运行；面试题先闭卷回答，再查看参考回答，最后用复习卡检查遗漏。

- 知道函数定义、调用、参数和返回值的基本组成。

- 能准确解释 Python 的参数传递模型，不只说“值传递”或“引用传递”。
