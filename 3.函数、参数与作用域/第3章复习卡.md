# 第 3 章复习卡：函数、参数与作用域

本卡用于学完后的快速回忆，不替代完整讲义。

## 1. 函数调用的执行步骤

```text
读取函数对象
→ 从左到右计算实参表达式
→ 根据签名绑定形参
→ 建立本次调用的局部作用域
→ 执行函数体
→ return 返回对象，栈帧结束
```

形参是本次调用中的局部名字。调用不是把调用者变量本身交给函数，而是让形参绑定到实参表达式得到的对象。

## 2. 基础术语

| 术语 | 快速回忆 |
|---|---|
| 函数对象 | 执行 `def` 时创建、可以保存和传递的对象 |
| 函数名 | 当前绑定到函数对象的名字 |
| 调用 | 使用 `()` 执行函数体 |
| 形参 | 函数定义中接收对象的局部名字 |
| 实参 | 调用时提供的表达式及其计算结果 |
| 签名 | 形参的名称、类别、顺序和默认值等调用接口信息 |
| 栈帧 | 一次函数调用保存局部名字和执行位置等状态的运行结构 |
| 副作用 | 除返回值外，对外部可观察状态产生的改变 |
| 接口 | 调用者能够观察和依赖的输入、输出、异常与副作用约定 |
| 状态 | 程序当前保存的数据和值 |
| 包装器 | 在原函数前后增加行为并把调用转交给原函数的函数 |
| 模块全局 | 当前 `.py` 模块顶层命名空间中的名字，不是所有文件共用的万能全局 |
| 双下划线名称 | Python 为特殊属性和协议预留的一类名称，完整机制在第 6 章学习 |

## 3. `return`

- `return value` 返回对象并立即结束本次调用。
- 没有显式 `return`，或者只写 `return`，返回 `None`。
- `return first, second` 实际返回一个元组。
- `print()` 负责显示，`return` 负责把对象交还调用者，二者不能互换。

## 4. 五类形参

```python
def example(pos_only, /, normal, default=0, *args, keyword_only, **kwargs):
    pass
```

| 类别 | 调用方式 |
|---|---|
| 仅限位置形参 | 只能由位置实参绑定，位于 `/` 之前 |
| 位置或关键字形参 | 两种实参方式均可 |
| 可变位置形参 `*args` | 收集多余位置实参，得到元组 |
| 仅限关键字形参 | 位于 `*` 或 `*args` 之后，只能由关键字实参绑定 |
| 可变关键字形参 `**kwargs` | 收集多余关键字实参，得到字典 |

默认值是形参的附加配置，不是第六类形参。对于位置或关键字形参，没有默认值的形参应位于有默认值的形参之前。

## 5. 定义中的星号与调用中的星号

- 定义中的 `*args`：收集额外位置实参。
- 定义中的 `**kwargs`：收集额外关键字实参。
- 调用中的 `*values`：把可迭代对象展开为位置实参。
- 调用中的 `**mapping`：把字符串键映射展开为关键字实参。
- 展开后若同一形参被绑定两次，会抛出 `TypeError`。

## 6. 形参默认值

默认表达式在执行 `def`、创建函数对象时计算一次，而不是每次调用重新计算。

危险模型：

```text
默认列表对象创建一次
→ 多次省略该形参对应的实参
→ 多次调用都绑定到同一个列表
→ 修改不断累积
```

常见处理：

```python
def collect(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items
```

如果 `None` 本身是有效业务值，应建立专用哨兵：

```python
MISSING = object()
```

## 7. Python 的对象共享传参模型

比较稳妥的表达是：**Python 采用对象共享传参，也可以说对象引用按值传递。**

```text
调用前：caller_name ──→ 对象
调用后：caller_name ──→ 同一个对象 ←── parameter_name
```

- `parameter_name = new_object`：只重新绑定函数局部名字。
- `parameter_name.append(x)`：通过共享引用修改对象，调用者可能看到变化。

不要只回答“值传递”或“引用传递”，因为这两个词在不同语言背景下容易产生歧义。

## 8. LEGB

名字读取按下面顺序查找：

```text
Local 局部作用域
→ Enclosing 外层函数作用域
→ Global 模块全局作用域
→ Built-in 内置作用域
```

注意：LEGB 描述名字读取顺序，不表示赋值会自动沿这条链修改已有名字。

## 9. `UnboundLocalError`

如果函数体中对某个名字赋值，Python 通常把它视为局部名字。即使读取写在赋值之前，也不会先退回全局寻找：

```python
count = 10

def change():
    print(count)
    count = 11
```

调用时读取的是尚未绑定的局部名字，因此出现 `UnboundLocalError`。

## 10. `global` 与 `nonlocal`

| 声明 | 修改目标 |
|---|---|
| `global name` | 模块全局作用域中的名字 |
| `nonlocal name` | 最近的、已经存在该绑定的外层函数作用域 |

- `nonlocal` 不能用于创建一个不存在的外层绑定。
- `nonlocal` 不指向模块全局作用域。
- 能通过参数和返回值表达的数据流，通常比大量修改全局状态更清楚。

## 11. 作用域高频规则

- 函数调用会建立新的局部作用域。
- 普通 `if`、`for` 和 `while` 不建立独立块级作用域。
- 模块顶层名字属于模块全局作用域。
- `globals()` 返回模块全局名字映射；`locals()` 用于观察当前局部映射，不应靠修改其结果控制局部变量。
- 内层函数可以读取外层函数名字。
- 修改外层函数名字通常需要 `nonlocal`。
- 不要用 `list`、`dict`、`sum` 等名字遮蔽内置对象。

## 12. 函数也是对象

- `other = function` 保存的是函数对象，没有调用。
- `result = function()` 才执行函数并保存返回值。
- 函数可以放进列表或字典。
- 函数可以作为另一个函数的参数。
- 函数可以作为返回值。
- `callable(value)` 判断对象是否可以使用调用语法。

高阶函数至少接收函数作为参数，或者返回函数。

## 13. 函数注解

```python
def add(left: int, right: int) -> int:
    return left + right
```

- 注解表达接口意图并帮助工具检查。
- 静态检查器主要分析代码和注解，不需要真正执行这次业务调用。
- Python 默认不会仅因为注解而自动拒绝其他类型。
- 注解可以从 `function.__annotations__` 观察。
- 完整的 `typing` 和静态检查在第 11 章学习。

## 14. 递归检查清单

写递归前依次确认：

1. 最小问题是什么？
2. 终止条件是否覆盖它？
3. 每次调用是否让规模严格接近终止条件？
4. 当前层等待下一层返回什么？
5. 返回值怎样逐层组合？
6. 最大深度是否可能超过 Python 限制？

递归深度为 `n` 时，调用栈额外空间通常为 `O(n)`。CPython 通常不进行尾递归优化。

尾递归表示递归调用是返回前最后的核心动作；尾递归优化表示复用当前调用空间。CPython 通常仍建立新栈帧，所以不能靠尾递归绕过深度限制。

## 15. 常见陷阱

- 把函数对象 `function` 与调用结果 `function()` 混淆。
- 用 `print()` 代替 `return`。
- 把可变对象直接写成默认值并在函数中修改。
- 误以为重新绑定形参能改变调用者名字。
- 误以为“函数没有返回”与“函数返回 `None`”不同。
- 同一形参同时通过位置和关键字绑定。
- 认为 `*args` 是列表；它是元组。
- 认为 `**kwargs` 接收任意键；调用关键字名称必须是字符串。
- 认为 LEGB 会让局部赋值自动修改全局名字。
- 滥用 `global` 保存函数结果。
- 忘记递归终止条件或没有缩小问题规模。
- 认为函数注解会自动强制运行时类型。

## 16. 面试回答骨架

回答参数传递问题：

```text
先说明形参是局部名字
→ 它绑定到实参表达式得到的对象
→ 区分重新绑定与修改对象
→ 用可变对象例子验证
```

回答作用域问题：

```text
先按 LEGB 确定读取位置
→ 检查函数体是否存在赋值
→ 决定是否形成局部名字
→ 再判断 global 或 nonlocal 是否改变规则
```

回答递归问题：

```text
终止条件
→ 规模怎样缩小
→ 当前层等待什么返回值
→ 时间复杂度
→ 调用栈空间
```
